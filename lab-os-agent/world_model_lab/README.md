# world_model_lab — 一个可运行的「世界模型」原型

> **场景**：西安航空学院 · 计算机与人工智能学院 · 智能科学与工程系 · 信息物理融合系统创客空间 · 地面巡检小车
> **目标**：把「世界模型 / World Model」从概念落到可解释、可训练、可形式化验证的真实代码，嵌入彭老师的实验室 OS Agent 体系。

## 1. 为什么做这件事？

2025–2026 年，业界已把 AI 演进划成四阶段：

> 感知 AI → 生成式 AI → 代理 AI → **物理 AI（Physical AI）**

其中**物理 AI** 的核心是「让 AI 理解真实世界的物理规律、能预测行动后果、能在物理世界里闭环」。而**世界模型**就是这个闭环的**大脑/想象空间**：它负责回答「如果我做这个动作，世界会变成什么样」。

在彭老师的管理体系里，这一点有天然落点：

- 实验室名就叫 **信息物理融合系统（CPS）创客空间**，世界模型正是 CPS 的 AI 升级版；
- 之前定义好的 **P1 软件 / P2 嵌入式 / P3 物联网 / P4 智能系统** 四能力域，恰好构成一个完整物理 AI 系统的四块拼图：**P1=推理大脑、P2=执行本体、P3=感知-连接神经系统、P4=智能/世界模型**；
- 彭老师长期关注**可验证 AI / 形式化方法**，而世界模型的最大软肋正是「想象出的轨迹可能越界/超速/幻觉」——这正好是形式化方法大显身手的地方。

因此本项目不只要"加一个概念"，而是交付一个**真的、可跑的、可验证的**世界模型原型。

## 2. 项目结构与核心文件

```text
world_model_lab/
├── dynamics_env.py      # 真实世界：2D 实验室巡检小车动力学环境
├── world_model.py       # 世界模型：从 (s,a)→(s',r) 数据学出动力学
├── planner.py           # 规划器：在世界模型内用 CEM 做 MPC 想象规划
├── formal_verify.py     # 形式化验证：z3 符号化执行线性动力学，验证安全不变量
├── demo.py              # 端到端演示 + 可视化
├── assets/NotoSansSC-Regular.ttf  # 为 matplotlib 提取的简体中文 ttf
└── figs/                # 演示生成的图（.png）
```

### 2.1 真实世界：`dynamics_env.py`

- 状态 `s = [x, y, vx, vy]`：小车在实验室平面的位置与速度。
- 动作 `a = [ax, ay]`：加速度指令。
- 线性地面真值：
  ```
  x'  = x + vx·dt + 0.5·ax·dt²
  vx' = (vx + ax·dt)·(1 − damp·dt)
  ```
- 包含实验室边界、禁区（桌子/设备）、目标区。
- 提供 `linear_params()`，把真动力学写成标准线性形式 `s' = A·s + B·a`，供世界模型和 z3 复用。

### 2.2 世界模型：`world_model.py`

**LinearWorldModel**：用岭回归从数据中学习 `s' = A·s + B·a + c`。因为地面真值是线性的，所以能学到**近乎零误差**的动力学。这是最关键的教学点：

> 世界模型不是黑盒拟合一切，而是学习环境的**动力学规律**，并用这个规律"脑补"未来。

也提供一个可选的轻量 **NeuralWorldModel**，用于演示更复杂/非线性的潜空间模型。

### 2.3 规划器：`planner.py`

- **MPC**：在世界模型内随机采样动作序列，评估后果，选回报最高者。
- **CEM（交叉熵方法）**：更专业的 model-based RL 规划器，迭代优化动作序列分布，能从"朝目标方向"的初值出发收敛到可行解。

关键能力：**完全在想象里规划，不消耗真实世界资源**——这正是世界模型价值所在（机器人学/自动驾驶里 "在仿真里失败一千次，真实世界只成功一次"）。

### 2.4 形式化验证：`formal_verify.py`

对世界模型学得的线性动力学做 **z3 符号化可达性验证**：

- 问：从某个初始集合出发、在 H 步内执行任意合法动作，**是否必然**保持安全（不越界、不超速、不撞禁区）？
- 等价于检查：是否存在一条动作序列，使某一步违反安全不变量。
- 若 z3 返回 `sat` → 找到**可复现的违规反例**（动作序列 + 完整轨迹）。
- 若 z3 返回 `unsat` → 可证明对所有动作序列都安全（确定性保证）。

`physical_ai_guard()` 进一步演示 **物理 AI 修正闭环**：

1. 世界模型想象出违规动作；
2. 物理 AI（嵌入公理的约束层）把动作幅度收紧；
3. 重新形式化验证，直到可证明安全。

## 3. 快速运行

```bash
cd lab-os-agent/world_model_lab
python3.11 demo.py
```

输出：

- 控制台报告（世界模型误差、MPC 规划结果、形式化验证结论）

## 5. 与实验室管理体系的对接

| 层级 | 对应能力 | 本原型中的落点 |
|---|---|---|
| **P1 软件** | 推理大脑 | `world_model.py` 学出的动力学模型 |
| **P2 嵌入式** | 执行本体 | `dynamics_env.py` 中的小车真实执行层 |
| **P3 物联网** | 感知-连接神经系统 | 小车的位置/速度观测；未来可替换为摄像头/激光雷达 |
| **P4 智能系统** | 智能/世界模型 | `planner.py` 的 MPC/CEM + `formal_verify.py` 的可验证闭环 |
| **物理 AI 闭环** | 感知→推理→行动→反馈 | 世界模型内部 "脑补" → CEM 规划 → 真实 env 执行 → 反馈数据再训练 |
| **可验证 AI** | 安全不变量 | z3 证明/证否 "想象出的轨迹是否安全"，违规即修正 |

## 6. 可扩展方向（供学生进阶）

- **非线性世界模型**：把真实动力学加摩擦/限幅，训练 NeuralWorldModel。
- **部分可观**：只给小车摄像头图像（像素），学潜空间世界模型（RSSM/Dreamer 风格）。
- **Sim-to-Real**：把仿真中学到的世界模型参数迁移到真实小车上。
- **更复杂安全属性**：用 z3 验证 "小车永远不进入某危险区"、"两小车不碰撞" 等。
- **与 lab-os-agent 接入**：把世界模型作为能力向导里 "P4 智能系统" 的标志性成果：学生大三/大四要做出一个「可验证世界模型驱动的巡检小车」作为 MVP。

## 8. 权衡与边界

- **线性模型 vs 真实世界**：本原型默认地面真值为线性，因此线性世界模型可零误差复现。真实机器人往往非线性，此时应切到 `NeuralWorldModel`，并容忍一定模型误差。
- **形式化验证目前只覆盖线性动力学**：非线性/神经网络世界模型的验证是开放研究问题（hybrid system 验证、神经网络可达性工具如 α,β-CROWN 等），可作为研究生课题。
- **CEM 规划是启发式**：不保证全局最优，但比随机采样稳定，适合 8GB 显存/CPU 本地运行。
