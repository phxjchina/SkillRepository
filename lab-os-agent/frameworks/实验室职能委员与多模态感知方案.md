# 实验室职能委员与多模态感知方案

> 来源：彭老师微信补充（2026-09-15）——实验室日常管理的**岗位清单**与**两类多模态感知智能体**需求。
> 定位：作为 `lab-os-agent` Skill 的**职能委员映射层 + 感知层**知识源；与既有 6 专家、双端口、被动行为信号感知（情绪体系 §3.5）协同，不重复造轮子。
> 底座：本地离线（Ollama + Bonsai-27B + 本地 CV/音频推理），隐私不出本机；沿用"自主性为底座 / 心理不越界 / 管理不越界 / 推断非监视"护栏。

---

## 一、职能委员体系（9 委员 ↔ Agent 能力映射）

彭老师补充的实验室日常管理岗位共 **9 个委员**：安全、心理、卫生、技术、宣传、组织、体育、财务、资产。
每个委员对应 Agent 的一项能力或一条感知通道；Agent **承接其"可结构化、可提醒、可记录"的部分**，决策与处置权始终在彭老师与学生本人。

| 委员（岗位） | 对应 Agent 能力 / 专家 | 类型 | Agent 承接内容 | Agent 边界（不越位） |
|------|------|------|------|------|
| **技术委员** | 技术专家（已有） | 对话 / 代码 | 技术路线建议、项目审核、代码质量评审、任务卡派发 | 复杂难题如实交教师兜底 |
| **心理委员** | 情绪专家 + 多模态心理感知 | 对话 + 图像 + 声音 | 状态识别、陪伴引导、异常上报 | 心理危机**立即上报**，不自行处理 |
| **安全委员** | 安全感知 Agent（视频） | 视频 | 安防巡查、火警检测、学习在位检测 | 仅预警上报，**不处置** |
| **卫生委员** | 卫生检查（安全卫生制度 §2.4） | 台账 / 图像 | 卫生/用电安全检查表、异常上报 | 记录 + 上报，不处罚 |
| **组织委员** | 组织协作（协作与分流 KCN） | 排期 / 签到 | 活动/例会的排期、签到、待办跟踪 | 排期 + 提醒，不替人决策 |
| **宣传委员** | 宣传沉淀（技术交流制度） | 归档 / 宣传 | 成果宣传稿、技术分享归档、知识沉淀 | 归档 + 宣传，不替代真人表达 |
| **体育委员** | 体育健康（新增维度） | 活动 / 出勤 | 体育锻炼提醒、健康促进、出勤观察 | 提醒 + 促进，**不强制** |
| **财务委员** | 财务台账（事务性工作管理） | 台账 | 经费流水、报销提醒、台账更新 | 台账 + 提醒，**不审批** |
| **资产委员** | 资产台账（事务性工作管理） | 台账 / 交接 | 设备/资产清单、交接确认、盘点提醒 | 台账 + 交接确认，不处置 |

> **与既有架构的关系**：9 委员不是新增 9 个"专家"，而是把真人岗位**映射**到已有的 6 专家 + 2 感知通道上——技术/心理委员落在对话侧专家，安全委员落在视频感知通道，其余落在制度/台账侧。导师端口（管理驾驶舱）据此聚合出"委员视图"，彭老师一眼看到每个委员维度的状态与异常。

## 二、多模态感知层（两类本地感知智能体）

在既有"被动行为信号感知（情绪体系 §3.5，基于对话与活动）"之上，新增**视频**与**图像+声音**两类本地被动信号源。它们**升级而非替代** §3.5：§3.5 处理"说了什么/做了什么"，感知层处理"画面与声音里呈现什么"。

### 2.1 视频感知 Agent（看）—— 学习状况 / 安全 / 火警

- **输入**：实验室公共区摄像头视频流（**本地 RTSP/USB，经学生明示同意**），实时抽帧做本地 CV 推理，**原始视频不落云、不长期留存**。
- **三类输出信号**：

| 信号 | 检测内容 | 触发动作 | 推送对象 |
|------|----------|----------|----------|
| 学习状况 | 在位检测、专注度（头部朝向/停留时长）、空位/早退 | 更新考勤与"有效实验室时长"，异常纳入弹性考勤台账 | 彭老师（聚合）+ 相关学生 |
| 安全 | 危险行为（违规用电、攀爬、危险物品）、陌生人闯入 | 立即预警 + 事件快照（加密、限时） | 彭老师（紧急） |
| 火警 | 烟雾 / 火焰检测 | **最高优先级**紧急推送，附事件快照 | 彭老师（即时）+ 实验室告警 |

- **实现建议**：本地目标检测（如 YOLO 类）+ 烟雾火焰分类模型离线推理；优先在 8GB 显存内跑轻量模型（如 YOLO-Nano / MobileNet 类），与 Ollama 错峰使用。
- **价值排序**：火警检测安全价值最高、误用风险最低，建议作为感知层**首个试点**。

### 2.2 多模态心理感知 Agent（图像 + 声音）—— 心理状态

- **输入**：学生交流时的**图像**（表情 / 姿态 / 视线）与**声音**（语速、停顿、语调、音量），均为本地采集、本地推理。
- **输出**：心理状态**粗判**（如平静 / 低落 / 激动 / 疲惫），带**置信度**，作为情绪专家（心理委员）的**辅助信号**，与对话文本信号交叉印证。
- **实现建议**：本地表情识别 + 语音情绪分类（轻量模型），仅在学生主动交流场景触发，不主动监听。
- **边界**：**仅是信号，不是诊断**。最终心理状态判定由情绪专家结合对话上下文给出，危机信号一律上报彭老师。

## 三、感知层与 §3.5 被动感知的关系

| 维度 | §3.5 被动行为信号感知（已有） | 本方案多模态感知层（新增） |
|------|------|------|
| 信号源 | 对话关键词、活动/周报行为 | 视频画面、图像表情、声音特征 |
| 触发 | 学生主动对话/提交 | 本地 CV/音频推理（被动采集） |
| 隐私敏感度 | 中（文本/行为） | **高（画面/声音）** |
| 处理 | 本地 LLM 推断 | 本地 CV/音频模型推断 |
| 关系 | 基础层 | **升级扩展层，共用同一套护栏与置信度机制** |

> 两条通道结论汇入同一份"学生状态画像"，导师端口按"信号来源"标注，彭老师可区分"他说"与"画面/声音显示"，避免单一来源误判。

## 四、强化版隐私与护栏（针对视频 / 音频高敏感）

在 `lab-os-agent` 既有 7 条护栏之外，针对视频/音频采集**额外强化**：

1. **同意知情**：摄像头/音频采集须学生**明示同意**，公告用途、范围、时长；可随时撤回。
2. **空间边界**：仅覆盖**公共实验区 / 会议区**，**绝不**覆盖宿舍、洗手间、私人空间。
3. **本地优先、不落云**：视频/音频流与推理**全程本地**；原始数据不留存（除非告警事件快照，且加密、限时自动清除）。
4. **信号优先于隐私内容**：用行为/表情/声音**特征**，不读取私聊、私人文件、生理数据。
5. **置信度 + 可纠偏**：所有感知结论带置信度，彭老师/学生可纠正，结论可回滚。
6. **不处置**：感知到异常**仅预警上报**，处置权在彭老师。
7. **模型天花板**：本地 CV/音频为轻量小模型，精度有限，作**辅助信号非判决定论**；复杂判定交教师。
8. **双端口隔离**：感知原始画面/声音**不向学生端口**泄露，仅聚合后的脱敏状态进入驾驶舱。

## 五、落地节奏（试点 → 审阅 → 全量）

沿用彭老师一贯的"小范围试点 → 审阅映射表 → 全量执行"三段式：

1. **试点（低风险先行）**
   - 先上**无感知**的台账类委员：财务、资产、卫生、组织、宣传、体育（纯结构化提醒/记录，零隐私争议）。
   - 对话侧：技术委员、心理委员（已有对话能力）直接承接。
   - 感知层**仅试点火警检测**（安全价值高、误用风险低、最优首试点）。
2. **审阅**：彭老师看 2 周委员台账质量与火警预警准确率，调阈值与推送频率。
3. **全量**：扩到视频学习状况 + 图像+声音心理感知，开放前完成同意知情流程与空间边界配置。
