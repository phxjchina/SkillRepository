## 零、元框架：实验室 OS Agent 即世界模型（2026-09-15 彭老师修正）

> **核心认知**：彭老师明确要求——**把对实验室学生的管理、把整个实验室 OS Agent 本身，作为一个"世界模型"来理解**。因此，本体系最高层的视角是：**lab-os-agent 就是一个对"实验室世界"的内部模型**，而非一堆被动响应工具。

- **世界模型四要素（管理域）**：状态 S（学生能力/情绪/进度、资源、制度、氛围）· 动作 A（提醒/分配/推送/干预/授权/复盘）· 动力学 T（"提醒→进度推进""推送→三观微调→行为改变"）· 推演（先在想象里想清楚再执行）。
- **组件即模型**：双端口=模型两面；六专家=维度推理器；职能委员=职能执行/感知代理；多模态感知层=观测输入；物理 AI 北极星=行动闭环外延；主动自动化/护栏=自驱时钟/约束边界——它们**共同构成**这个世界模型。
- **与可验证 AI 对接**：管理动力学 T 可形式化为状态机/逻辑 → 可推演、可验证、可审计，直接落在彭老师"可验证 AI / 形式化方法"方向上。
- **同名异义澄清**：此"管理世界模型"是体系 Meta 层（对人/组织）；而 P4 物理 AI 方向的"物理世界模型"（`world_model_lab/` 小车原型）是技术层（对物），仅作同构示例与教学类比。

> 完整定义见 [`实验室世界模型_体系即世界模型.md`](实验室世界模型_体系即世界模型.md)。下文 §1.6–§1.7 的"世界模型"特指 P4 物理 AI 技术线，勿与本节管理视角混淆。

## 一、技术架构（能力培养体系）

### 1.0 能力域优先级（彭老师定调 · 由易到难）

> 四个能力域**全部保留**，但学生入门与 Agent 推送**按以下优先级编排**：从最容易上手的软件系统起步，逐级迈向最难的智能系统，形成"先建立成就感、再攻坚硬核"的路线。

| 优先级 | 能力域 | 由易到难的理由 |
|--------|--------|----------------|
| **P1** | 信息处理系统开发能力（软件） | 纯软环境、零硬件依赖、反馈最快，最易建立"我能做出来"的成就感 |
| **P2** | 嵌入式系统开发能力 | 引入电路/单片机，需软硬结合，门槛高于纯软件 |
| **P3** | 物联网系统开发能力 | 在嵌入式之上叠加网络协议、云端、端到端链路，复杂度再升一档 |
| **P4** | 智能系统开发能力 | 涉及数学基础与 ML/DL 体系，抽象度与算力要求最高，压轴 |

- 该优先级直接对应 §1.1 四大能力域表；Agent 的"技术教练"据此把 P1 作为零基础学生的默认起点，P4 作为高阶跃迁目标。
- 与"三个改变 / 自主性底座"一致：先让小产品跑起来（P1）→ 制造外部刺激下的正向情绪 → 再逐级加难，避免一上来啃智能系统导致挫败（对应情绪图谱中"动力缺失/无动机"风险）。

### 1.6 P1–P4 → 物理 AI 整合（2026-09-15 彭老师指示）

彭老师要求把**物理 AI（Physical AI）**纳入实验室管理体系作为研究北极星。关键洞察：**既有 P1–P4 四能力域，恰好是一个完整物理 AI 系统的四块拼图**——

| 能力域 | 在物理 AI 系统中的角色 | 对应技术栈层 |
|--------|------------------------|--------------|
| P1 软件 | 推理/决策大脑（AI 模型·规划·LLM） | 规划/决策层 |
| P2 嵌入式 | 行动/执行本体（边缘控制·执行器·实时控制） | 底层伺服 + 边缘运行时 |
| P3 物联网 | 感知-连接神经系统（传感器·通信·数据上下行） | 感知层 + 通信 |
| P4 智能系统 | 智能/世界模型（CV·NLP·ML/DL·世界模型） | 世界模型层 |

> 学生按 P1→P2→P3→P4 螺旋进阶，本质是在**依次造出物理 AI 系统的四块拼图**；制高点是把四块**集成**成能跑"感知—推理—行动—反馈"闭环的本地物理 AI 小系统（如桌面机械臂分拣、实验室巡检小车），在创客空间亲手落地。本实验室"信息物理融合系统"身份即 CPS，物理 AI 是"长了 AI 大脑的新一代 CPS"。完整定义、概念层级与护栏对齐见 `物理AI与实验室管理体系融合方案.md`。

### 1.7 P4 物理世界模型层：技术示例（对物，与 §0 管理世界模型同名异义）（2026-09-15 彭老师指示）

**彭老师 2026-09-15 修正**："世界模型"的主导含义见 §0——**把整个 lab-os-agent 作为对实验室世界的内部模型**。本 §1.7 是 P4 物理 AI 方向的一个**技术示例**：把"世界模型"在物理域（小车/机械臂）做成可运行原型，作为教学类比；**它不等于"世界模型"本身**（"世界模型本身"是 §0 的体系 Meta 框架，对人/组织）。

#### 三层结构

| 组件 | 角色 | 原型文件 |
|---|---|---|
| **地面真值动力学** | 真实世界（小车/机械臂） | `world_model_lab/dynamics_env.py` |
| **世界模型** | 从 `(s,a)` 数据学习 `s'=f(s,a)`，在想象里预测未来 | `world_model_lab/world_model.py` |
| **想象规划器** | MPC / CEM：在世界模型内优化动作序列 | `world_model_lab/planner.py` |
| **形式化验证层** | z3 符号执行，验证安全不变量/找反例 | `world_model_lab/formal_verify.py` |

#### 与物理 AI 闭环的精确关系

- **感知半环** = 视频/图像+声音感知层（见 `实验室职能委员与多模态感知方案.md`）；
- **推理半环** = 本世界模型层（负责"如果这么做，会发生什么"）；
- **行动半环** = P2 嵌入式 + P1 软件驱动执行器；
- **反馈半环** = 真实执行后的数据再回流训练世界模型，形成 Sim-to-Real 闭环。

#### 学生培养落点

- **大三下学期/大四**：标志性成果为「可验证世界模型驱动的实验室巡检小车 MVP」；
- **能力向导里程碑**：P4 智能系统阶段必须交付一个能跑通"训练→规划→验证"闭环的物理 AI 小系统；
- **AIOPC 产品库**：将可复用的世界模型模块作为 P4 产品登记，供低年级复用与扩展。

#### 差异化研究价值

世界模型的核心局限（误差累积、OOD 幻觉、越界）与形式化方法天然互补，是彭老师"可验证 AI"方向的论文级抓手：

- 线性动力学可用 z3 符号执行做可达性/不变量证明；
- 非线性/神经网络世界模型可接入 NNV、α,β-CROWN、Barrier Certificate；
- 多智能体碰撞、时序安全属性可用 SMT/SMT-LIB 验证。

物理世界模型技术原型的四大家族辨析、形式化验证路径见 `world_model_lab/README.md`；管理视角"世界模型"完整定义见 [`实验室世界模型_体系即世界模型.md`](实验室世界模型_体系即世界模型.md)（§0）。

## 二、管理架构（实验室治理体系）

### 2.1 治理哲学：经线 + 纬线

来自《制度总则》：
- **经线（流程标准化）**：全生命周期管理，保障组织稳定运行。
- **纬线（能力工程化）**：阶梯式能力培养，实现人才迭代升级。
- 最终目标：建立以项目交付为核心的绩效评估体系，构建"自我驱动、技术传承、资源高效"的精英工程师社区。

### 2.2 全生命周期四大关键控制节点（KCN）

| 节点 | 管理目标 | 依据制度 |
|------|----------|----------|
| **准入与定岗** | 入口控制：导师集权 + 学生代管，四级梯队定岗 | 《组织架构与管理方案》 |
| **运行与监控** | 过程控制：周报、弹性考勤、例会复盘 | 《周报制度》《弹性考勤制度》《工作会议制度》 |
| **协作与分流** | 动态控制：老带新、考研/就业分流 | 《技术交流制度》《考研与考公学生专项管理规定》 |
| **交付与传承** | 出口控制：代码/文档/硬件移交、知识产权归档 | 《交接制度》《事务性工作管理制度》 |

### 2.3 组织架构（导师 + 四级梯队）

```
导师（最高决策）
  └── 大四核心管理层
      ├── 实验室总负责人（组长）：行政总控、上传下达、人员考核
      ├── 技术总负责人（副组长）：技术路线、项目审核、标准制定
      ├── 技术方向小组长（5人）：物联网 / 嵌入式 / 人工智能 / 游戏设计 / 系统分析与设计
      └── 职能委员（9 委员，2026-09-15 彭老师补充）：组织委员、宣传委员、技术委员、心理委员、安全委员、卫生委员、体育委员、财务委员、资产委员
      └── 大三 / 大二 / 大一年级组长（各设组长+副组长）
```

> **四级梯队**：大四总控 → 大三中坚 → 大二执行 → 大一储备。
> **9 委员 ↔ Agent 能力映射**：每个委员对应一项 Agent 能力或感知通道（技术/心理委员落对话侧专家，安全委员落视频感知，其余落制度/台账侧）。完整映射、边界与落地节奏见 `实验室职能委员与多模态感知方案.md`，导师端口据此聚合"委员视图"。

### 2.4 制度子系统清单

| 制度 | 核心要点 | Agent 角色 |
|------|----------|------------|
| **周报制度** | 周报是实验室"血液循环系统"；任务颗粒度、进度百分比、交付成果 | 定时提醒、模板发放、汇总审核 |
| **弹性考勤** | 大一大二取消无效打卡，改为项目里程碑考核 | 记录有效时长、里程碑达成 |
| **会议制度** | 管理层会议、技术例会、项目验收会 | 会前通知、会议纪要模板、待办跟踪 |
| **技术交流制度** | 技术分享会、项目复盘会、工具工作坊、代码会诊；大一/大二强制参与 ≥80% | 活动排期、签到记录、知识点归档提醒 |
| **考研/考公专项** | 大三下分流备案，建立绿色通道，任务减负但底线不破防 | 状态标记、进度跟踪、导师预警 |
| **事务性工作管理** | 学生助理岗位：经费、资产、技术资料、IT 资源、合同跟踪 | 提醒填报、台账更新、交接确认 |
| **交接制度** | 大四离校前"无交接不毕业"；代码可运行、文档可阅读、新人可上手 | 交接清单、50%理解度考核记录 |
| **安全卫生制度** | 安全用电、防火、卫生保持 | 安全检查表、异常上报 |

### 2.5 与 Agent 的接口

- **制度管理员 persona**：负责周报/考勤/会议/技术交流/交接等制度的提醒、记录、上报，不自行处罚。
- **心理陪伴 persona**：在考研分流、受挫、动力缺失等节点，用学业情绪图谱提供支持。
- **信念叙事者 persona**：把周报、里程碑、项目成果升维为"三个改变"意义叙事。

### 2.6 感知层（视频 / 图像+声音 · 多模态被动信号 · 2026-09-15 补充）

在 §2.5 对话/台账侧接口之外，新增两类**本地**被动信号源，补足"看得见的信号"：

- **视频感知（安全委员承接）**：学习状况（在位/专注度）、安全（危险行为/陌生人）、火警（烟雾/火焰，最高优先级紧急推送）。本地抽帧 CV 推理，原始视频不落云。
- **多模态心理感知（心理委员承接）**：图像（表情/姿态）+ 声音（语速/停顿/语调）→ 心理状态粗判（带置信度），作为情绪专家辅助信号。

> 两类信号汇入学生状态画像，按来源标注，与 §3.5 被动行为信号感知（对话/活动）交叉印证。全部遵守**强化版护栏**：同意知情、空间边界（仅公共实验/会议区）、本地不落云、信号优先、置信度可纠偏、不处置、模型天花板、双端口隔离。完整设计见 `实验室职能委员与多模态感知方案.md`。
