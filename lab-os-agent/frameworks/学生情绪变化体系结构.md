# 学生情绪状态体系结构（教育心理学视角）

> 承接：`2026-09-11` 日常感悟（范畴/叙事重构/宏大叙事意义感）+ 个人发展·心得四（宏大叙事式训练体系）。
> 本结构是《学生信念体系与宏大叙事框架》的**情绪引擎子系统**：把"宏大叙事"变成可被触发的**情绪场**，让学生在共造的叙事世界里持续处于正向、自驱的情绪态。
> **方法论内核**：借鉴"穷举式心理状态分类"的古典思想方法（已用现代心理学术语全面重写，全文不含任何宗教内容），重点落在**可识别、可引导**的学生情绪/动机状态的穷举与映射——即把学生在叙事中的每一种情绪都"挂号建档"。
> **v3 修订（去宗教化）**：原古典心性分类术语已全部替换为教育心理学 / 学习心理学 / 心理咨询术语；以"自主性"为底座——学生有自主性、情绪波动是自主性的自然产物、教师只提供外部刺激、学生持自己的状态地图自主响应。

## 0. 理论基座与关键澄清

**理论锚点（现代心理学整合框架）**

| 理论 | 核心主张 | 在本体系中的用途 |
|------|----------|------------------|
| 学业情绪理论（控制-价值理论） | Pekrun：情绪随"控制感 × 价值感"起伏 | 解释成就感 / 挫败感从何而来 |
| 自我决定理论 SDT | Deci & Ryan：自主 / 胜任 / 归属三需求 | 内驱力的来源 |
| 心理资本 PsyCap（HERO） | Luthans：希望 / 效能 / 韧性 / 乐观 | 可开发的积极心理资产 |
| 心流理论 Flow | Csikszentmihalyi | "心流态"的学术定义与触发条件 |
| 积极情绪拓展-建构 | Fredrickson | 正向情绪拓展认知与资源 |
| 成长型思维 | Dweck | 能力可塑 → 对抗认知固化 |
| 集体效能 / 共同体感 | Bandura / McMillan | "共同体态"的心理基础 |
| 意义建构 Meaning-making | 意义治疗 / 积极心理学 | "超越态"与三个改变的内化 |
| 学习投入 Engagement | 学业投入研究 | 投入态 → 心流的连续谱 |
| 元认知 Metacognition | Flavell | 自我觉察、拉回主线、抗分心 |

> 本体系把学生在叙事世界里的情绪/动机状态做"穷举式分类"，重点放在可识别、可干预、且**尊重自主性**的那部分；本质是一张**学生情绪/动机状态图谱（A–E 五组 + 状态地图）**。

**设计哲学（自主性为底座）**：学生是有**自主性**的人，不是被控制的机器人——**正因为有自主性，情绪才会出现真实的起伏波动，这是健康信号而非 bug**。教师只负责提供"**外部刺激**"（叙事事件、环境、反馈），学生则依据自身的**状态地图**自主响应、自主流转。本体系只做两件事：**让学生看清自己的地图 + 让教师提供高质量的外部刺激**。详见 §6 护栏。

> **情绪采集双通道（回应"学生不愿主动倾诉"的质疑）**：本体系不依赖学生主动开口。除"主动自述"通道（情绪地图卡 / 周报状态滑条）外，增设"被动行为信号推断"通道——学生在代码、任务、周报、产出中的**行为痕迹**天然暴露其情绪与动机状态，系统据此**推断而非监视**。详见 §3.5。

## 1. 心理状态 → 学生情绪态映射（核心表）

把学生常见情绪/动机状态按教学可用度分为 5 组：基础认知、动机投入、积极品质、困扰偏差、波动过渡。每组给出：**状态 → 学生场景（学生在该状态下的自主表现） → 外部刺激（教师可提供的触发） → 期望行为（学生自主趋近的方向）**。

### A 组 · 基础认知与情绪体验——情绪体验与行动意向的基础
| 状态 | 学生场景（自主表现） | 外部刺激（教师提供） | 期望行为 |
|------|----------|----------|----------|
| 注意唤起 | 注意力被"实验室有意义"吸引 | 启蒙叙事、空间锚点 | 从涣散转入关注 |
| 真实接触 | 接触真实项目 / AIOPC 任务 | 给可上手的小产品 | 建立真实连接 |
| 情绪感受 | 体验成就感 / 挫败感 | 意义看板、及时反馈 | 情绪被"看见" |
| 意义表征 | 对"改变世界"取相、形成画面 | 三个改变口号、主角称谓 | 内化叙事 |
| 行动意向 | 造作——决定投入还是放弃 | 角色卡"你是主角" | 转化为行动意向 |

### B 组 · 学习动机与认知投入——投入与专注的发动机
| 状态 | 学生场景（自主表现） | 外部刺激（教师提供） | 期望行为 |
|------|----------|----------|----------|
| 目标动机 | 想做出自己的 AIOPC 产品 | 给清晰可选题（aioppc 想法） | 产生目标欲 |

## 2. 情绪状态地图（学生自主流转）

把学生在叙事世界里的情绪流转建模为**状态地图（state map）**。

**关键前提（贯穿全篇）**：教师**只提供外部刺激**，状态之间的跳转由学生**自主完成**——因为学生有自主性，同一刺激下不同学生可能落在不同状态，且会自然起伏波动，这是**预期且 desirable**的，不是系统故障。

- **教师侧（可控）**：外部刺激 → 激活某些心理状态
- **学生侧（自主）**：依据自身状态地图，自主映射到情绪态 → 自主产生行为

| 状态 | 主导心理状态 | 外部刺激（教师提供） | 学生自主响应（状态地图） | 期望行为 |
|------|----------|----------|----------|----------|
| 涣散 / 游离（初始） | 分心、疲惫、失焦 | 学生初入实验室 + 启蒙：三个改变 + 主角角色卡 | 被吸引、开始关注（自主） | 转入关注 |
| 唤醒 / 激活态 | 注意唤起、目标动机、自我效能 | 反复嵌入叙事、往届案例 | 主动取相、产生目标欲（自主） | 主动问"我能做什么" |
| 投入态 | 韧性坚持、持续记忆、专注投入 | 可上手的 aioppc 小产品 + 真实项目 + 难度梯度 | 自主投入、保持专注（自主，会起伏） | 持续训练 |
| 心流态 | 沉浸安定、专注投入、洞察、平稳抗扰 | 产品跑通、被真实使用 + 意义看板、及时正反馈 | 进入心流、享受过程（自主高峰） | 享受并深耕 |
| 迷茫 / 受挫态 | 信任缺失、动力缺失、浮躁、受挫愤怒 | Bug / 失败 / 被否定 + 失败复盘 + 同伴叙事 + 复原文化 | 自主经历波动后恢复（关键：教师不替他平复） | 恢复投入 |
| 共同体态 | 自尊内控、责任共情、良性竞争、持续记忆 | 周度"我们这周改变了什么" + 共同体层叙事 | 自主生发出责任感（自主） | 协作、责任感 |
| 超越态 | 确定理解、清醒务实、洞察 | 把坐标升到 L4–L6 的叙事牵引 | 自主内化"改变世界"认同（自主） | 内化"改变世界"自我认同 |

> 状态地图闭环：涣散 → 唤醒 → 投入 → 心流 →（受挫）→ 共同体 → 超越 → 反过来强化唤醒。每一次循环，学生对叙事的"自我效能"更牢一层。**情绪波动是闭环里的正常呼吸，教师不必、也不应抹平它**。

## 3. "小世界"叙事架构（外部刺激场）

把实验室设计成**外部刺激场**——教师只设计刺激，不直接指定学生的响应状态。四类刺激对应四组设计动作：

| 刺激类型 | 刺激设计（教师侧） | 激活的心理状态 | 预期效果 |
|----------|----------|------------|------|
| **空间** | 实验室=改变世界的现场（L1 锚点）、主角工位 | 注意唤起、意义表征、自我效能 | 入境即被叙事包裹 |
| **仪式** | 周度复盘"我们这周改变了什么" | 持续记忆、自尊内控、责任共情、良性竞争 | 共同体态固化 |
| **语言** | 三个改变口号、主角称谓、AIOPC 黑话 | 意义表征、目标动机、确定理解 | 范畴 / 叙事持续重塑 |
| **反馈** | 意义看板、真实用户使用数据 | 情绪感受、沉浸安定、韧性坚持 | 正向情绪被"看见"并强化 |

> 教师控制的是"刺激的质量与真实性"，不控制"学生落到哪个状态"。这是自主性底座的直接推论。

### 3.5 被动情绪感知（不依赖主动倾诉的行为信号推断）

**问题背景**：有同行教师质疑——学生普遍不愿主动吐露情绪，若情绪管理只能靠学生开口，架构将在"沉默多数"身上形同虚设。本小节给出对策：用**可观察的行为痕迹**替代主动倾诉，作为情绪/动机状态的推断输入。

**理论基座（正统学术，非监视）**

| 方法 | 来源领域 | 在本体系中的用途 |
|------|----------|------------------|
| 数字表型 Digital Phenotyping | 计算行为科学 / 学习分析 | 用可观察的"数字行为痕迹"推断心理/情绪状态 |
| 学习分析 Learning Analytics | 教育技术 | 从学习行为数据挖掘投入度、困难信号 |
| 行为信号情绪识别（轻量、非生理） | Affective Computing | 从交互行为模式识别情绪/动机态 |
| 过程性评估 Formative Assessment | 教育心理学 | 用过程数据（非考试）刻画学习状态 |

> **关键区分：被动感知 ≠ 监视（surveillance）**。监视是"持续、隐蔽、以控制为目的地追踪个体私密"；被动感知是"在知情同意下，用公开可观察的产出/过程数据，以**关怀**为目的推断可能的状态"，且结论带置信度、可被学生纠偏。二者在意图、透明性、可逆性上本质不同。

**信号源分层（越靠上越优先、越公开、隐私风险越低）**

| 层级 | 信号示例 | 可推断状态 | 隐私/自主性 |
|------|----------|-----------|-------------|
| L1 产出/过程（公开） | 任务卡完成率、单任务卡壳时长、代码提交频率与时序、返工率、里程碑延期 | 动力缺失 / 受挫愤怒 / 分心误判 / 浮躁 | 高（公开可观察） |
| L2 制度/节律 | 周报按期/迟交/缺交、考勤弹性达标、预约与回应延迟 | 动力缺失 / 松散 / 疲惫掉线 | 高 |
| L3 交互（半被动） | 与 Agent 对话的提问频次、问题类型迁移、反复同问、长时无交互 | 困惑 / 受挫 / 掉线 | 中（对话本地、知情同意） |
| L4 peer | 小组互评、peer review 中他人对协作状态的间接描述 | 人际冲突 / 责任共情偏低 | 中（需去标识） |
| L5 弱主动（低门槛） | 周报内置"状态滑条 1–5"、情绪地图卡一键 emoji 勾选 | 任意（自述补充） | 学生自主、可空 |

**从信号到状态的推断逻辑（映射回 §1 五组 + §2 状态地图）**

- 连续 ≥ N 天零提交 + 周报缺交 + 里程碑延期 → 推断 **动力缺失/分心（D 组）**，对应状态地图"涣散/游离"支线；
- 长期卡同一任务 + 反复同问 + 返工率走高 → 推断 **受挫/认知偏差（D 组）**，对应"迷茫/受挫态"；
- 提交稳定 + 任务按期 + 对话有深度追问 → 推断 **投入/洞察（B、C 组）**，对应"投入态/心流态"；
- 产出质量下滑 + 自评偏高 → 推断 **自满/浮躁（D 组）**。

推断结果写入档案 `emotion.inferred_state` + `inferred_confidence`（置信度），与学生的主动自述 `emotion.current_state` **并列共存、互不覆盖**，供教师端口对照参考。

**与自主性底座的对齐（护栏）**

1. **透明知情同意**：学生入学即被告知"系统会基于你的产出/过程数据做关怀式状态推断"，且**能随时看到自己被推断的状态与依据**；
2. **行为优先于私密**：优先用 L1–L2 公开行为信号；**不读取私聊、私人文件、生理数据**；
3. **弱干预优先**：推断到低落，先发低压迫关怀/资源，**不直接上报导师**，除非触及红线（安全/严重危机，见 §6）；
4. **结论带置信度、可纠偏**：推断是概率性的，从不贴死标签；学生可一键标记"推断有误"，系统据此修正，避免偏见固化；
5. **本地处理**：信号聚合与推断全在本地 Bonsai 完成，不出本机；
6. **不替代真实关系**：推断只用于"提醒教师谁可能需要关注"，最终判断与关怀仍由教师/真人完成。

> §3.5 与 §3"外部刺激场"构成闭环：**刺激 → 学生行为反应（含自主波动）→ 行为信号被被动采集 → 推断状态 → 优化下一轮刺激质量**。学生全程不须开口，且仍持状态地图自主响应。

## 5. 使用方式（赋能自省，而非操纵）

1. **学生自省工具**：发"情绪地图卡"，让学生看见自己当前处在哪个状态组合、哪个状态，主动调适（**赋能**）。
2. **教师刺激设计工具**：在训练四阶段（启蒙 / 训练 / 产出 / 闭环）各预设"想激活的心理状态 + 对应外部刺激"，但**不预设学生必须到达的状态**。
3. **诊断工具**：某生卡在"信任缺失 / 动力缺失"→ 查 §1 D 组对应刺激（真实交付支撑 + 共同体叙事）；卡在"自满 / 小成即傲"→ 更高坐标对标。诊断后仍是"优化刺激质量"，而非"强制扭转状态"。
4. **被动感知（不靠学生开口）**：详见 §3.5——从代码提交、任务卡完成率、周报节律、产出质量、与 Agent 交互等**行为信号**推断情绪/动机态，作为主动自述的补充与兜底，覆盖"沉默型"学生；推断结果带置信度、可纠偏。

## 6. 风险护栏（关键 · 必读）

> 本体系最危险的方向是滑向**单方面情绪操纵**。必须守住以下红线，否则将触发此前框架已列的"被工具化 / 语言过度重塑"风险，并背离"改变自己"的自主成长逻辑。

| 红线 | 要求 | 对策 |
|------|------|------|
| **自主性是底座** | 学生有自主意志、情绪自然起伏、可质疑可退出 | 教师只给刺激不控响应；叙事可证伪 |
| 不靠情绪空转 | 情绪必须以真实能力成长支撑 | L0–L4 真实交付是前提（呼应之前框架） |
| 不制造依赖 / 崇拜 | 避免对教师 / 叙事的盲信 | 培养元认知与质疑精神 |
| 教师自省 | 设计者也可能被自己的叙事反噬 | 教师自身持"清醒、质疑、平稳" |
| 不损个体福祉 | 意义感不得替代休息 / 学业 / 心理健康 | 精力边界、最低学业线 |
| **推断非监视** | 被动感知是关怀式状态推断，不是隐蔽监视 | 透明知情同意 + 行为信号优先于私密内容 + 结论带置信度且可纠偏（见 §3.5） |

**以"自主性"为底座的本位说明**：您已明确——学生有自主性，不是被控制的机器人；**正因为有自主性，情绪才会起伏波动，这是真实、健康、且必要的过程**。因此本体系的正确用法是：**教师只给予外部刺激，学生持自己的状态地图自主响应**。所谓"情绪随设计而动"，精确地说应是"**情绪随外部刺激、经学生自主地图而起伏**"——教师不直达学生的内部状态，只负责刺激的质量与真实交付的支撑。把人当纯粹被控对象去单向操纵，既违背"自主性"这一前提，也会因"被工具化"反噬（学生识破后信任崩塌）。自主性是本体系最好的护栏。
