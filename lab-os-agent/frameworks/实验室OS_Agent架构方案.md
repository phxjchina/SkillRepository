# 实验室 OS Agent 架构方案（双端口 · 多专家 · 主动自动化）

> 决策（彭老师拍板 2026-09-11）：多专家编排 + 主动自动化 + 双端口统一 Skill `lab-os-agent`
> 整合对象：原 `lab-training-agent`（学生侧培训陪跑）并入，新增**导师侧管理驾驶舱**
> 底座：六大框架知识库 + 13 产品项目库 + 本地 Ollama + Bonsai-27B（隐私不出本机）

---

## 一、整体架构

```
            ┌───────────────── 导师端口（彭老师用 · 管理驾驶舱）─────────────────┐
            │  全局看板：技术进展 / 情绪态势 / 制度合规 / 里程碑                   │
            │  主动推送：周报催收·里程碑预警·情绪异常·合规风险 → 推送彭老师        │
            └───────────────────────────┬──────────────────────────────────────┘
                                         │ 共享学生档案 + 六大框架知识库
            ┌───────────────────────────┴──────────────────────────────────────┐
            │                        路由 Agent（Router）                        │
            │  识别诉求类型 → 分发到对应专家；挂定时/事件触发器做"主动管理"        │
            └───┬──────┬──────┬──────┬──────┬──────┬─────────────────────────────┘
                │      │      │      │      │      │
            [技术]  [情绪]  [制度]  [信念]  [能力]  [实验]
             专家    专家    专家    专家    专家    专家
            （各只加载自己那块框架文档做 RAG，上下文干净、可控、可回滚）
                                         │
            ┌───────────────────────────┴──────────────────────────────────────┐
            │           学生端口（被陪跑 · 即原 lab-training-agent 六角色）        │
            │  技术陪跑 / 心理陪伴 / 信念叙事 / 能力向导 / 实验设计 / 制度提醒      │
            └──────────────────────────────────────────────────────────────────┘

            ┌─────────── 多模态感知层（本地 CV/音频推理 · 被动信号源）────────────┐
            │  [视频感知] 学习状况 / 安全 / 火警 ─┐                              │
            │  [图像+声音感知] 心理状态粗判 ───────┤→ 汇入 Router / 导师端口状态画像 │
            └────────────────────────────────────┘                              │
               （强化版护栏：同意知情·空间边界·本地不落云·置信度可纠偏·不处置）

**一句话**：对外是一个"懂您实验室的虚拟管理专家"，对内是六边形子专长 + 一个路由调度 + 一层本地多模态感知，跑在本地小模型上，主动替您盯技术、情绪、制度三件大事，并用视频/图像+声音补上"看得见的信号"。

> **职能委员体系（2026-09-15 彭老师补充）**：实验室日常管理设 9 委员——安全/心理/卫生/技术/宣传/组织/体育/财务/资产。每个委员映射到一项 Agent 能力或感知通道（详见 [`实验室职能委员与多模态感知方案.md`](实验室职能委员与多模态感知方案.md)），导师端口据此聚合出"委员视图"。

## 二、双端口职责

### 导师端口（管理驾驶舱 · 彭老师视角）
| 能力 | 说明 |
|------|------|
| 全局看板 | 聚合所有学生的技术进展、情绪态势、制度合规、里程碑达成 |
| 主动推送 | 周报未交名单、里程碑到期预警、情绪异常学生、合规风险，自动推给彭老师 |
| 管理建议 | "该激励谁 / 该介入谁 / 谁卡在 P4 攻坚"，给出基于数据的建议 |
| 产品视角 | 对接 13 产品项目库，看哪些学生产品可进 MVP 孵化 |

### 学生端口（培训陪跑 · 学生视角 = 原 lab-training-agent）
技术陪跑、心理陪伴、信念叙事、能力向导、实验设计、制度提醒——六角色照旧，仅从"独立 skill"变为"统一 OS 的学生侧入口"。**学生如何登录与日常使用，见《学生接入与部署指南》。**

## 三、多专家编排（Router + 6 专家）

| 专家 | 路由识别信号 | 加载框架（RAG） | 输出 |
|------|--------------|----------------|------|
| 技术专家 | 学生问技术 / 做项目 / 代码 | 技术架构与管理架构提炼（§1 P1–P4） | 任务卡 / 代码评审 / 复杂题交教师 |
| 情绪专家 | 受挫 / 情绪词 / 倾诉 | 学生情绪变化体系结构（情绪图谱 A–E + §2 状态地图） | 识别状态 → 安慰 + 引导（自主性底座） |
| 制度专家 | 违规 / 懈怠 / 制度节点 | 管理架构（§2 八项制度子系统） | 提醒 + 记录 → 必要时上报教师（不处罚） |
| 信念专家 | 日常陪伴 / 里程碑达成 | 学生信念体系与宏大叙事框架（三个改变 + 七层阶梯） | 意义叙事 + 坐标提醒 |
| 能力专家 | 阶段推进 / 考核 | 学院学生训练体系方案（训练四阶段 + 8 学期） | 阶段判定 + 下一里程碑 |
| 实验专家 | 做产品 / aioppc | AIOPC 学生项目规划（13 产品 P1–P4 映射） | 产品陪跑 + 任务卡拆解 |

> **适配本地小模型的关键**：每个专家只加载自己那块框架，绝不把六大框架全塞进一个 prompt——避免 Bonsai-27B context 溢出与跨域幻觉。路由层只做"分类 + 选专家 + 拼装上下文"。

#### 3.1 职能委员体系（9 委员 ↔ Agent 能力映射 · 2026-09-15 补充）

彭老师补充实验室日常管理 9 委员：安全 / 心理 / 卫生 / 技术 / 宣传 / 组织 / 体育 / 财务 / 资产。委员不是新增 9 个专家，而是把真人岗位**映射**到既有 6 专家 + 2 感知通道；导师端口据此聚合"委员视图"。完整映射与边界见 [`实验室职能委员与多模态感知方案.md`](实验室职能委员与多模态感知方案.md)。

| 委员 | 对应 Agent 能力 | 类型 |
|------|----------------|------|
| 技术委员 | 技术专家（已有） | 对话/代码 |
| 心理委员 | 情绪专家 + 多模态心理感知 | 对话+图像+声音 |
| 安全委员 | 安全感知 Agent（视频：学习/安全/火警） | 视频 |
| 卫生委员 | 卫生检查（安全卫生制度） | 台账/图像 |
| 组织委员 | 组织协作（协作与分流 KCN） | 排期/签到 |
| 宣传委员 | 宣传沉淀（技术交流制度） | 归档/宣传 |
| 体育委员 | 体育健康（新增维度） | 活动/出勤 |
| 财务委员 | 财务台账（事务性工作管理） | 台账 |
| 资产委员 | 资产台账（事务性工作管理） | 台账/交接 |

#### 3.2 多模态感知层（本地 CV/音频 · 被动信号源）

在 §3.5 被动行为信号感知（对话/活动）之上新增两类本地被动信号：

- **视频感知 Agent（看）**：学习状况（在位/专注度）、安全（危险行为/陌生人）、火警（烟雾/火焰，最高优先级紧急推送）。本地抽帧推理，原始视频不落云。
- **多模态心理感知 Agent（图像+声音）**：表情/姿态 + 语音情绪（语速/停顿/语调），输出心理状态粗判（带置信度），作为情绪专家辅助信号。

两类信号汇入同一份"学生状态画像"，按来源标注，与对话信号交叉印证。全部遵守**强化版护栏**（同意知情、空间边界、本地不落云、信号优先、置信度可纠偏、不处置、模型天花板、双端口隔离）。

#### 3.3 物理 AI：实验室研究北极星（2026-09-15 彭老师指示）

彭老师要求把**物理 AI（Physical AI）**作为实验室管理体系的研究北极星。本实验室"信息物理融合系统"即 CPS，物理 AI 是"长了 AI 大脑的新一代 CPS"。

**核心映射**：既有 **P1 软件 / P2 嵌入式 / P3 物联网 / P4 智能系统** 四能力域，恰好是一个完整物理 AI 系统的四块拼图——P1=推理大脑、P2=执行本体、P3=感知-连接神经系统、P4=智能/世界模型。学生按 P1→P4 进阶，本质在依次造出四块拼图，制高点是集成成能跑"感知—推理—行动—反馈"闭环的本地物理 AI 小系统。已建的**视频/图像+声音感知层 = 该闭环的"感知"半环**，"行动/执行"半环（P2 控制 + P1 软件 + P4 决策）是学生在创客空间亲手造的另一半。

> 物理 AI 的透彻定义、与世界模型/具身智能/CPS 的层级区分、三条技术路线与护栏对齐，见 [`物理AI与实验室管理体系融合方案.md`](物理AI与实验室管理体系融合方案.md)。

#### 3.4 世界模型：实验室 OS Agent 作为世界模型（管理视角）（2026-09-15 彭老师修正）

**彭老师明确修正**：所谓"世界模型"，**不是 AI 技术里的潜空间动力学模型，而是指把对实验室学生的管理、把整个实验室 OS Agent 本身，作为一个世界模型来理解**。这是一种管理 / 元认知视角的框架，是整个体系的**元框架**。

- **本质**：lab-os-agent 对"实验室社会技术世界"的内部模型——持续维护实验室状态 S，理解管理动作 A 如何驱动状态演化 T，并能推演"如果这么做，实验室会怎样演化"。
- **四要素**：状态 S（学生能力/情绪/进度、资源、制度、氛围）· 动作 A（提醒/分配/推送/干预/授权/复盘）· 动力学 T（"提醒→进度推进""推送→三观微调→行为改变"）· 推演（先在想象里想清楚）。
- **组件即模型**：双端口=模型两面、六专家=维度推理器、委员=职能执行/感知代理、感知层=观测输入、物理 AI 北极星=行动闭环外延、护栏=约束边界——它们**共同构成**这个世界模型（不是某个模块）。
- **可验证落点**：管理动力学 T 可形式化为状态机/逻辑 → 可推演、可验证、可审计，直接对接彭老师"可验证 AI / 形式化方法"方向（作用在"人/组织"）。
- **同名异义澄清**：此"管理世界模型"是体系 Meta 层（对人）；而 P4 物理 AI 方向的"物理世界模型"（`world_model_lab/` 小车原型）是技术层（对物），仅作同构示例与教学类比，**不是"世界模型"的主导含义**。

> 完整定义、四要素、组件映射、同名异义澄清见 [`实验室世界模型_体系即世界模型.md`](实验室世界模型_体系即世界模型.md)；物理世界模型技术原型见 `world_model_lab/README.md`。

## 四、主动自动化机制

### 定时任务（导师端口主动推送）
| 触发 | 动作 | 推送对象 |
|------|------|----------|
| 每周一 09:00 | 周报催收 + 上周未交名单聚合 | 彭老师 + 相关学生 |
| 每里程碑日 | 进度检查 + 风险标红（延期/卡壳） | 彭老师 |
| 每周末 | 情绪周度复盘（从学生本周对话聚合成态势） | 彭老师 |
| 每月 1 日 | 能力雷达更新（P1–P4 进度分布） | 彭老师 |

### 事件触发
| 事件 | 动作 |
|------|------|
| 学生提交周报 | 自动批阅合规 + 触发信念叙事（成就锚定） |
| 学生对话出现情绪关键词 | 情绪专家介入 + 异常（自伤/严重抑郁倾向）立即上报教师 |
| 学生违规/懈怠 | 制度专家记录 + 上报，不自行处罚 |
| 学生选做产品 | 实验专家按 P1–P4 派任务卡 |

> **落地说明**：定时/事件触发器的可部署配置（cron + WorkBuddy 自动化 task JSON）与 **7 条推送 prompt 模板**，已独立成文件 [`实验室OS自动化配置.md`](实验室OS自动化配置.md)；学生档案六域字段定义见 [`学生档案schema.md`](学生档案schema.md)。部署阶段按宿主接入这两份即可。

## 六、本地化与护栏（硬性，写入系统 prompt）

1. **自主性为底座**：只给外部刺激与引导，不强制扭转学生状态。
2. **心理不越界**：心理危机必须立即上报教师，不得自行处理。
3. **管理不越界**：仅有提醒/记录/上报；处罚与最终处置权在彭老师。
4. **本地化**：学生档案仅存本地，不上云、不外传。
5. **模型天花板**：Bonsai-27B 为本地小模型，复杂技术难题如实说明并交教师兜底。
6. **双端口隔离**：导师端口数据（聚合看板/预警）不向学生端口泄露个体隐私评价。

## 七、落地节奏（试点 → 审阅 → 全量）

1. **试点（3–5 人，大二下–大三）**：先跑导师端口的"周报催收 + 里程碑预警" + 学生端口的"技术 + 制度"。
2. **审阅**：彭老师看两周推送质量，调 Router 分类阈值与推送频率。
3. **全量**：扩到全实验室，接入情绪周度复盘与产品 MVP 孵化。
