# 视野拓展样本库（文化范畴相对性 · 陪跑用）

> 配套：`学生信念体系与宏大叙事框架.md` §9「文化范畴相对性与视野拓展机制」
> 用途：信念专家在陪跑中，按学生的**原生范畴 + 当前坐标层**，推送「相邻一层」的异质文化范畴样本，使其**遭遇别的可能 → 松动原生认知刚性 → 看见"改变自己"的真实起点**。
> 理论根（见 §9）：范畴论/文化相对性——不同文化范畴的人"可感知的世界"不同；**见世面 = 遭遇异质范畴 → 意识到自己坚守的并非唯一 → 三观松动 → 行为改变**。

---

## 一、使用原则（呼应 §9.1，先读）

1. **原生范畴为锚**：先认学生"从哪来"的范畴（如"考上编制才叫出息"），不把新范畴当敌人硬塞；推送的对照样本用于"开窗"，不是"砸墙"。
2. **只推相邻一层**：学生坐标在 L_k，只给 L_{k+1}（或横向同层异质范畴）的样本，不做 L0→L6 的跳跃，避免 §6"范畴重构反噬"。
3. **双轴标注**：每个样本带 `地域轴 × 轨迹轴 × 价值轴` 标签，便于匹配学生画像。
   - 地域轴：山区 / 县城 / 一二线 / 海外
   - 轨迹轴：体制内 / 工程 / 开源 / 科研 / 创业 / 公益
   - 价值轴：稳定 / 自由 / 意义 / 财富 / 自主可控
4. **不自决**：样本只呈现"有人这样活过 / 这样想过"，**绝不替学生选定人生**；这与边界护栏 1（自主性为底座）、7（推断非监视）一致。
5. **真实感优先**：样本为示意性叙事原型（非真人实名），但须具体、可代入；避免口号化，让学生读后确有"原来还可以这样"的冲击。

---

## 二、样本清单

> 字段：编号 | 适配层（推给坐标在此层附近的学生的"相邻范畴"） | 双轴标签 | 范畴一句话 | 真实感片段

---

**S1 ｜ 适配 L0（自我可塑）｜ 县城 / 工程 / 自由**
- **范畴一句话**：一个普通二本生，也能从"做题家"变成"建造者"。
- **真实感片段**：某二本计算机专业学生，大一默认自己"只能考公"。大二在 GitHub 上给一个开源项目修了个文档错字，顺手补了个测试用例被合并。第一次收到陌生维护者的"thanks，this is helpful"时，他意识到"我写的代码能被不认识的人用"。自我标签悄悄从"做题家"改写成"建造者"——这一步，没人替他上思政课。

---

**S2 ｜ 适配 L0（原生范畴松动）｜ 山区 / 体制内 vs 技术 / 稳定**
- **范畴一句话**："出息"不止一种形状，技术也能回哺家乡。
- **真实感片段**：甘肃山区来的学长，全家共识是"考上编制才叫出息"。他在实验室接触到一个做嵌入式助农设备的团队——用低成本的传感器帮老家监测大棚温湿度。看到"用技术回哺家乡"也是一条被尊重、被需要的路，他第一次觉得"编制之外，好像也行"。稳定不是只有一种形状。

---

**S3 ｜ 适配 L0→L1 ｜ 县城 / 开源 / 自主**
- **范畴一句话**：底子差不是终点，"被需要"的体验能重建自我效能。
- **真实感片段**：职高起点转本科的学生，长期自认"底子差、跟不上"。导师没让他啃大部头，只让他维护实验室内部一个小工具（自动拉取实验日志）。半年后这个工具被三个实验室共用。他第一次有了"我创造了被别人需要的东西"的体验——自我效能感来自真实交付，不是来自被夸。

---

**S4 ｜ 适配 L1→L2 ｜ 一二线 / 产品 / 意义**
- **范畴一句话**：实验室的产出，能直接改变学院。
- **真实感片段**：学生团队用本地 AI 链路（Ollama + 小模型）做了个给视障同学读屏的小应用，原本只是课程作业。被学院采纳为无障碍设施后，他们发现"实验室做的东西不只给自己玩，它能改变学院里真实的人"。意义锚点从 L1 跳到 L2，不是靠喊，是靠被使用。

---

**S5 ｜ 适配 L2→L3 ｜ 跨校 / 开源协作 / 自主**
- **范畴一句话**："改变学校"可以自下而上，不必等上面发文件。
- **真实感片段**：几所高校的学生在开源社区协作一个教学平台，没有老师牵头，纯靠兴趣与代码。三年后这个平台进了多所学校的课表。它证明：改变学校不一定要当干部、写汇报，一群人持续写代码也能重塑培养范式。

---

**S6 ｜ 适配 L3→L4 ｜ 社会 / 开源 / 意义**
- **范畴一句话**："改变社会"不是口号，是有人在用你写的东西。
- **真实感片段**：一位毕业学长做的开源笔记工具，最初只为自己用。意外被海外开发者拿去做知识管理，GitHub star 破万，每天有真实用户在用。他后来说，最触动他的不是数字，而是一条 issue："your tool helped me keep my job during burnout。"——改变社会，发生在陌生人生活里。

---

**S7 ｜ 适配 L4→L5 ｜ 国家 / 自主可控 / 责任**
- **范畴一句话**："自主可控"从政策词变成手上的 commit。
- **真实感片段**：参与国产深度学习框架适配的同学，做的兼容性补丁进了主干。这意味着更多国内中小团队不必依赖国外闭源栈。他说，以前"自主可控"是新闻联播里的词，现在是他终端里的一行 `git commit -m "compat: add xxx support"`。国家尺度的事，落到个人是一行代码。

---

**S8 ｜ 适配 L5→L6 ｜ 地球 / 科研 / 人类尺度**
- **范畴一句话**：你的工作，可能是人类尺度的正增量。
- **真实感片段**：做可验证 AI 的博士生，把形式化验证用在医疗诊断辅助系统上。论文被一个低收入国家团队复用以提升基层诊断准确率。他意识到：自己写的那些看似抽象的证明，在地球另一端降低了误诊——这是 L6 地球层最不空泛的样子。

---

**S9 ｜ 适配 横向·文化范畴差异（中国 vs 美国）｜ 海外 / 创业 / 自由**
- **范畴一句话**：看见另一种范畴，你的"唯一正解"会裂开一条缝。
- **真实感片段**：在美交换的学生发现：硅谷把"失败"当数据、把"20 岁创业"当常态；而他把"稳妥读完书再进大厂"当唯一正解。两种范畴没有对错，但当他看见另一种也被尊重地活着，他那个"唯一正解"悄悄裂开了一条缝——缝隙里才是自由。

---

**S10 ｜ 适配 横向·价值排序差异（无对错）｜ 任意 / 公益 / 意义**
- **范畴一句话**：价值排序没有唯一正确解，只是意义来源不同。
- **真实感片段**：同宿舍两人：一个把"年薪"排第一去了大厂，一个把"能不能帮到人"排第一去做教育公益。十年后都过得去，只是意义来源不同——一个来自账面，一个来自回信。范畴没有唯一正确的排序，强求自己活成别人，才是内耗。

## 三、推送决策小表（信念专家调用指引）

| 学生当前坐标层 | 推送相邻样本（"下一个可能范畴"） | 推送意图 |
|----------------|----------------------------------|----------|
| L0（自我，原生范畴刚性） | S1 / S2 / S3 | 先松动"我只能这样"——让自我标签从"被定义"转向"可塑" |
| L0→L1（进实验室但觉打杂） | S3 / S4 | 让其体验"被需要 / 我创造了东西" |
| L1→L2（学院尺度初醒） | S4 / S5 | 看见实验室产出能改变更大共同体 |
| L2→L3（学校尺度） | S5 / S6 | 理解"改变学校"可自下而上 |
| L3→L4（社会尺度） | S6 / S7 | 感知真实用户在用自己写的代码 |
| L4→L5（国家尺度） | S7 / S8 | 把"自主可控"从词变成 commit |
| L5→L6（人类尺度） | S8 | 让地球层有最不空泛的锚 |
| 任何层 · 认知卡死 / 内耗 | S9 / S10（横向异质范畴） | 用"文化相对性"破除"唯一正确范畴"执念 |

> 注：推送后**观察**学生是否开始谈论"别的可能"（§9 试点指标），而非考核其是否"被说服"。共识与改变须由学生自发发生——这是护栏，也是尊重。
