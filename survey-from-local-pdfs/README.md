# survey-from-local-pdfs

把"一批本地下载的论文 PDF"当作**唯一**参考文献库，产出一篇**引用零幻觉**的中文系统文献综述（SLR 范式）。

## 功能

- **引用真实可溯**：所有引用必须 1:1 回溯到本地 PDF，绝不编造外部来源。
- **严格 SLR 结构**：摘要 → 1 引言（背景 / 二次研究方法 / 问题陈述 / 贡献）→ 2 研究方法（RQ / 来源与选择 / 纳入排除 / 质量评估 / 数据提取 / 流程）→ 3 执行 → 4 结果（文献计量 + 按 RQ 分析 + 研究特征总表）→ 5 讨论（综合 / 启示 / 效度威胁）→ 6 结论 → 参考文献 → 附录（研究特征总表）。
- **多视角分析**：配合 `literature-review` 技能模拟 3–5 个专家视角（MDE / 形式化 / LLM-SE / 安全 RL / 系统工程）梳理主题、共性、分歧、研究空白。
- **大纲生成**：配合 `survey-generation` 技能产出 SLR 大纲。
- **引用校验**：脚本内置断言 —— 所有 `[n]` 均有定义、所有文献至少被引一次（零悬空引用、零未引文献）。
- **产出 docx**：真实 Heading 1/2/3 样式、GB/T 7714 参考文献、研究特征总表（因无 TeX 环境、用户工作流为 Word）。

## 适用场景

- 用户有一批本地 PDF，要基于它们写综述，且**引用必须真实锚定已下载文献、不可编造外部来源**时。
- 用户明确要求"按系统文献综述（SLR）范式"写 —— 否则容易写成粗线条随笔。

## 用法

```bash
# 1. 盘点语料：生成 REFERENCES / STUDY 起始数组（best-effort，需人工补全作者/标题/分类）
python scripts/extract_refs.py <pdf目录>

# 2. 撰写综述（配合 literature-review / survey-generation 做多视角分析与大纲）
python scripts/survey_slr.py --out 综述.docx

# 3. 校验引用：脚本内置断言确保零幻觉（零悬空、零未引）
```

详细工作流与脚本参数见 `SKILL.md`。
