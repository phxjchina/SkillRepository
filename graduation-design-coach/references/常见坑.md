# 常见坑（逆转自往届高频雷区 · 学生自查速查）

> 来源：计算机学院《往届常见问题汇总》+ 审核清单全集 + **两届 17 人 52 份文档批量自检实测**（2026-09-24，详见 `coach_evolution_2026-09-24/自检汇总.md`）。每条给"踩坑表现 → 怎么避免"，标注历届踩坑率。

## 选题/任务书
1. **题目太大或太虚**（"XX技术研究"无对象）→ 用句式模板落到具体系统/方法。
2. **课题要求一句话了事、与主要内容重复** → 拆成可验收指标。
3. **成果形式写"系统说明书"** → 写"XX系统一套，毕业设计论文一份"。
4. **参考文献混入无关条目**（模板复制残留 Samsung SmartThings 等）→ 逐条核对与课题相关。
5. **文献著录错**（**历届最高频**：两届 17 人中 10 人的任务书都踩，18 处）：作者>3位未用「,等」；外文卷缺期号、页码重复（`012125-012125`）→ 按 GB/T 7714 逐条改。
6. **进度表断档/终点不是答辩日** → 6阶段时间连续对齐学院通知。

## 开题报告
7. **现状堆文献没评述** → 每小节末加"然而…本文从…切入"。
8. **第3部分比第1+2部分还短**（**历届最高频开题问题：13/17 人必踩，76%**）→ 第3部分写到全文一半以上。
9. **进度与任务书不一致** → 复制任务书6阶段再核对。
10. **完成时间留空**"20 年 月 日" → 填阿拉伯数字。
11. **残留模板提示文字**"(研究目的应该出现在这里…)" → 交前全文搜"（"检查。
12. **文献重复编号**（[2]与[12]同一篇）→ 去重后仍≥10篇。
13. **错别字漏字**（"客服"→"克服"、漏"统"字）→ 交前朗读校对一遍。
14. **封面题目与正文题目不一致**（如缺"柜"字）→ 复制粘贴题目，别手敲。

## 实施与过程
15. **零留痕**（没截图没记录）→ 每完成一个模块立刻截图+记日志，论文直接用。
16. **长期零进展拖到中期** → 周度对账；落后2周主动"缩范围保核心"并告知教师。
17. **工作记录空泛/次数不足** → 一周2次、写具体咨询问题与指导内容。
18. **中途换技术栈** → 违反铁律④，确需更换先和教师沟通并同步改任务书口径。

## 论文
19. **摘要写成心得体会**（"通过本次毕业设计我学到了…"）→ 五要素客观陈述。
20. **目录与正文标题/编号不一致、测试章编成第4章** → 定稿前用自动脚本+人工核对。
21. **图号重复/无图题** → 按章编排（图1-1），图题置图下方。
22. **本人实现<2/3** → 大篇幅抄概念综述充字数=工作量不饱满，抽检红线。
23. **英文术语前后不一致**（OpenGL/Value混用）→ 全文搜术语统一。
24. **文献凑数**：正文无标注、没读过的文献列上去（极端案例：历届有论文仅 2 篇参考文献）→ 答辩会被问参考文献[5]讲什么；文献是论文地基，开题后持续积累，定稿前≥15篇。
25. **抄袭/代写** → 查重不过+抽检毙+学术不端处分，绝对红线。

## 答辩
26. **PPT堆满字** → 一页一个观点，图多字少。
27. **超时** → 讲稿按10分钟练，删 gracefully。
28. **答不上就沉默/狡辩** → "这方面我考虑不足，后续会补充"。
29. **现场演示翻车** → 提前录屏兜底。
30. **资料袋缺件** → 按学院清单逐项核对（译文→意见页→原文装订顺序等）。

## 历届批量实测新增（2026-09-24，两届 17 人 52 份文档）

31. **结论写成"收获与体会"**（6/17 人踩：写"通过本次设计我学到了…"）→ 结论只写四件事：做了什么 + 结果如何 + 不足 + 展望；感想一句都别放。
32. **独立英文摘要缺失**（5/17 人：只有中文摘要）→ 写完中文摘要当天就翻译，放另起一页（Abstract + Key words，Times New Roman），别拖到定稿才发现。
33. **结论/正文出现"收获""心得"字样被扣分** → 交稿前全文搜"收获""心得""体会到"，一律删改。
34. **论文标题排版带空格**（"摘　要""目　录""致　谢"）→ 这是规范排版本身没错，但会让朴素文本检查误判"缺摘要/缺目录"；教练自检脚本已做空格兼容（见下方脚本演化记录）。

## 教师共性问题实测新增（2025届《毕业论文共性问题总结》彭老师原话提炼 · 2026-09-24 第二轮）

35. **需求分析章节标题写"XX需求分析"、正文出现"XX模块"** → 章节叫"XX需求"；需求分析阶段根本没有"模块"概念，模块是概要/详细设计才出现的，写了直接暴露阶段混乱。
36. **相关技术章节科普化**（介绍"Arduino开发板是什么""ESP8266模块介绍""Tomcat服务器介绍"）→ 相关技术只写"本设计用到它的什么特性、为什么选它"，别抄百科。
37. **图不居中/假居中** → 多数是图所在段落残留"首行缩进两字符"格式，全部去掉才能真正居中。
38. **图内文字小、字体风格不统一、箭头样式不一、流程图不规范** → 图中文字建议华文中宋加粗、形状放大让字占满形状、连线间距收紧，保证100%比例可读；全套图统一风格。
39. **有"总体架构设计"字样却不配总体架构图**，或配的是抽象通用图 → 凡写"架构/总体"必配针对本论文特定领域的架构图。
40. **设计实现章出现操作性内容**（"先点击这个，后部署那个"式操作手册）→ 删；论文写设计思想与实现方案，操作步骤放使用说明书/附录。
41. **表格后只有"介绍"没有"解释"** → 表格后要解释字段用处、约束、取值范围——这些表里看不出来的东西。
42. **界面/效果展示放错章**（放设计章）→ 统一放测试章。
43. **缩写简写不统一、同一英文缩写反复解释** → 首次出现解释一次并全文统一。
44. **图片太黑不考虑打印效果** → 深色底截图先调亮/换浅色主题再贴。
45. **三级以下小标题没缩进** → 按学院格式：三级以下小标题首行缩进两字符。

## 跨届批量实测新增（2026-09-24 第二轮，2023-2026 四届 70 份）

46. **中期稿被按终稿标准误判"缺摘要/目录/致谢"** → 阶段正常现象；自检脚本已加 `--stage mid/draft` 降级为"建议"，学生别被吓到，也别拿它当不写的借口。
47. **外文翻译被当论文检查出"缺英文摘要"等假报** → 外文翻译是独立文档类型，自检脚本已支持 `--type translation`（查字数≥3000、原文出处、模板残留）。
48. **AI 生成内容直接进中期稿**（教师批语原话"先把AI生成部分去掉再说"）→ AIGC 可用来列提纲、改语病，正文必须自己写；查重+AIGC检测双红线。
49. **进度拖延写进文件名**（教师批语"动作太慢了内容太少""抓紧时间完成主体内容！"）→ 中期检查的本质是进度对账，主体内容没做出来，格式再好也过不了。
50. **"第3部分偏短"跨四届稳定复现**（2023届11/12、2024届8/10、2026届在抽查样本中同样出现）→ 这是开题第一高频问题，写开题先攻第3部分。

## 附：自检脚本演化记录（教练端维护用）

- **v1.0.1 修正（来自两届批量实测）**：①结构检查（摘要/关键词/Abstract/目录/致谢）改用**空格容忍正则**（`摘\s*要` 等）——此前 17 份论文误报 46 条"缺结构"，实为标题间隔排版；②图/表号重复只统计**行首图题**并**过滤图表目录行**（点引线/行尾页码）——否则"图表目录 + 正文图题"=假重复。
- **v1.2.0 升级（来自 2023-2026 四届 70 份跨届实测）**：①新增 `--stage mid/draft` **阶段感知**——中期/初稿缺摘要/目录/致谢属阶段正常，自动降为"建议"（此前误判 35 处"缺结构"）；②新增 `--type translation` **外文翻译类型**——翻译文档不再被套论文结构检查出"缺英文摘要"假报；③参考文献 0 篇时提示"Word 自动编号会漏计，请人工复核"。
- 图/表号重复仍被标记的，先看论文是否带**无页码的图表目录**，人工确认后再改号；真正的重复才改。
