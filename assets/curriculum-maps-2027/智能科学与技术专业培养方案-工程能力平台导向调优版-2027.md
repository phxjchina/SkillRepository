# 智能科学与技术专业培养方案调优版
## ——工程能力培养平台导向（2027 版修订草案）

> 依据指导思想：以工程能力培养平台建设为目标，以计算机科学与技术、软件工程、物联网工程、人工智能及自动化等专业建设经验为基础，以开发**智能信息处理系统、智能嵌入式系统、智能物联网系统、智能控制系统**四类系统为目标，培养学生综合运用所学知识解决**复杂工程问题**的能力。能力目标切分为**信息系统开发、嵌入式系统开发、信息物理融合、人工智能算法及模型开发**四个子能力，子能力相互结合即可完成各种智能系统的开发。平台向内融合各专业学习/就业/竞赛/实践需求与教师科研竞赛用人需求，产出竞赛与科研成果、解决毕业设计质量问题；向外输出符合企业用人需求的准工程师。

---

## 一、专业能力目标（调优后的一句话表述）

**智科 = 构造智能系统**：以四类目标系统为"作品形态"，以四个子能力为"能力组件"，以工程能力培养平台为"训练场"，培养能综合运用所学知识解决复杂工程问题、直接输出可用智能系统的准工程师。

能力产出逻辑链：

```
四子能力（组件） ──组合──→ 四类智能系统（作品） ──产出──→ 竞赛/科研/毕设/就业（成果）
```

## 二、目标系统与能力要求

### 2.1 四类目标系统

| 编号 | 目标系统 | 定义 | 典型作品样例 |
|---|---|---|---|
| SYS-1 | 智能信息处理系统 | 对多源信息进行采集、清洗、分析、理解并输出决策信息的软件密集系统 | 行为识别分析系统、低空目标视频理解系统、行业数据挖掘平台 |
| SYS-2 | 智能嵌入式系统 | 算法模型部署于边缘硬件、软硬协同的实时智能系统 | Jetson 边缘视觉检测终端、智能航电数据采集与推理装置 |
| SYS-3 | 智能物联网系统 | "端—边—云"贯通、感知联网一体的物联网系统 | 智慧校园环境监测平台、低空安防物联网系统 |
| SYS-4 | 智能控制系统 | 感知—决策—执行闭环、具备智能算法的反馈控制系统 | 四旋翼姿态智能控制、智能云台随动系统、机器人运动控制 |

### 2.2 四个子能力

| 编号 | 子能力 | 内涵 | 可观测能力指标（学生能做什么） |
|---|---|---|---|
| B1 | 信息系统开发能力 | 需求分析→体系结构设计→集成→测试的全流程软件系统构建 | 能用 UML/SysML 建模一个完整系统；能完成多模块集成联调；能按工程规范交付 |
| B2 | 嵌入式系统开发能力 | 在 ARM/RTOS/Linux 边缘硬件上进行驱动、接口与推理部署开发 | 能裁剪部署 Linux 系统；能编写传感器驱动；能将模型部署到 Jetson 并满足实时性 |
| B3 | 信息物理融合能力 | 物理世界感知（传感）与数字世界计算（网络/控制执行）的融合贯通 | 能设计传感—传输—执行链路；能完成端边云协同方案；能搭建反馈控制回路 |
| B4 | AI 算法及模型开发能力 | 机器学习/深度学习算法的选型、训练、评估与工程化 | 能复现并调优经典模型；能针对场景选型训练；能完成模型量化与轻量化 |

### 2.3 子能力 × 目标系统 支撑矩阵

|  | B1 信息系统 | B2 嵌入式 | B3 信息物理融合 | B4 AI算法模型 |
|---|---|---|---|---|
| SYS-1 智能信息处理系统 | ●● | ○ | ● | ●● |
| SYS-2 智能嵌入式系统 | ● | ●● | ● | ●● |
| SYS-3 智能物联网系统 | ● | ●● | ●● | ● |
| SYS-4 智能控制系统 | ● | ●● | ●● | ●● |

> ●● 主责能力，● 重要支撑，○ 一般参与。**每一类系统都要求至少两个●●能力组合**——这正是"子能力相互结合即可完成各种智能系统开发"的落地表达。

### 2.4 复杂工程问题主线

四类系统实践项目均按工程认证"复杂工程问题"七特征设计，最低要求：①多约束（成本/实时性/功耗/安全）→ ②需多子能力协同 → ③无唯一标准答案 → ④需实验验证迭代。每学年限定至少 1 个复杂工程问题载体项目。

## 三、与现有轮廓的差距诊断

| # | 差距 | 证据 | 调优动作 |
|---|---|---|---|
| 1 | **智能控制系统方向完全空白**（感知→传输→处理→存储齐，唯缺"控制"闭环） | 现轮廓 §3.2 无一门控制类课程 | 新增《自动控制原理与智能控制》+《智能控制系统综合实践》 |

| 4 | 无统一的产出考核口径 | 竞赛/科研/就业无对应考核点 | 建三层考核指标体系（§七） |

## 四、课程内容修改

### 4.1 新增课程（补齐 SYS-4 智能控制系统）

**《自动控制原理与智能控制》（S5，3 学分，核心）**
- 内容：经典控制直觉版（一/二阶系统、根轨迹与频域的工程读图、PID 整定）→ 状态空间概览 → 智能控制（模糊控制、神经网络控制、强化学习控制入门）→ 案例全部用四类系统场景（云台随动、姿态控制、温度智能调控）。
- 定位：**应用级**（对标自动化专业"认知+会用"，不深推理论证明——与彭老师"最优化太难"同判断尺度）。
- 衔接：前置《高等数学》《人工智能数学基础》；支撑《智能控制系统综合实践》《无人机反制系统设计与仿真》。

**《智能控制系统综合实践》（S7，2 学分，集中实践）**
- 内容：依托工程能力培养平台，以四旋翼姿态控制/智能云台/机器人运动控制为载体，完成"建模→PID→智能控制算法→实物联调→指标测试"完整闭环。
- 衔接：综合运用 B2（嵌入式）+B3（信息物理融合）+B4（算法）三能力；成果直接可转化为竞赛作品与毕设。

### 4.2 现有课程按子能力链归位（含内容调整点）

| 能力链 | 课程（学期） | 内容调整点 |
|---|---|---|
| **B1 信息系统开发能力** | 系统分析与设计（S5）；系统集成与体系结构设计（S6）；软件工程基础（S4，共享） | 系统分析增加 SysML 与复杂工程问题定义方法；系统集成增加"面向四类系统的集成模式"专题，案例全部换成四类系统 |
| **B2 嵌入式系统开发能力** | 计算机组成与结构（S3，共享）；行业嵌入式系统（S6）；行业智能嵌入式系统综合实验（S6，集中实践） | 内容保持；实验项目对齐 SYS-2 作品要求（实时性指标入考核） |
| **B3 信息物理融合能力** | 物联网概论（S3）；智能信息感知技术（S6）；智能感知技术及应用（S6）；物联网技术应用综合实验（S6，集中实践）；**自动控制原理与智能控制（S5，新增）** | 感知类课程增加"感知→执行"闭环视角；控制课补齐融合链最后一环 |
| **B4 AI 算法及模型开发能力** | 智能科学公共基础 6 门（S3–S6，与 AI 共享：导论/数学基础/模式识别/机器学习/综合实验/深度学习A） | 内容保持共享不重复；综合实验项目选取面向四类系统的模型任务 |
| **四能力综合** | 智能系统创新设计（S6，与 AI/计科同题异构）；智能控制系统综合实践（S7，新增）；无人机反制系统设计与仿真（S7）；无人机编程与开发（S6）；无人机自组网技术（S7）；人工智能前沿技术（S7）；生产实习（S7）；毕业设计（S8） | 同题异构角色不变（AI 出算法/智科出集成/计科出载体）；毕设选题 S6 启动、S7 平台预研 |

### 4.3 能力递进学期路线图

```
S1-2  编程+数学底座                    → [工具层]
S3    导论·物联网概论·计算机组成        → [B4/B3/B2 启蒙]

S5    系统分析·模式识别·机器学习·自控   → [B1/B4/B3 主链成型]

```

## 五、培养体系结构

```
┌─────────────────────────────────────────────────────┐
│ 第四层：平台产出层   竞赛成果 / 科研成果 / 毕设 / 就业 │
├─────────────────────────────────────────────────────┤
│ 第三层：系统综合层   SYS-1~4 作品实战（S6-S8）        │
│         同题异构 · 智能系统创新设计 · 控制综合实践     │
├─────────────────────────────────────────────────────┤
│ 第二层：子能力链层   B1 信息系统链                    │
│         B2 嵌入式链  B3 信息物理融合链  B4 AI算法链   │
│         （每链配置"课程群 + 锚项目"）                 │
├─────────────────────────────────────────────────────┤
│ 第一层：能力基座层   数学底座 + 计算机公共底座（共享） │
└─────────────────────────────────────────────────────┘
         ↑ 基础经验来源：计科/软工/物联网/AI/自动化五专业
```

每条子能力链配置一个**锚项目**（贯穿该链 2–3 门课的同一载体项目）：B1→校园二手书交易系统重构；B2→Jetson 边缘检测终端；B3→智慧环境监测物联网；B4→行为识别模型训练与调优。锚项目成果自动进入平台作品库，供竞赛/毕设复用。

## 六、培养方式

1. **项目制（PjBL）贯穿**：每子能力链一锚项目，S6 起转入 SYS 级复杂工程问题项目，S7–S8 与毕设/竞赛贯通。
2. **平台四融合（向内）**：
   - **学习需求**：平台承接各课内实验实训，实验即项目组件；
   - **竞赛需求**：建立"竞赛矩阵"（电子设计竞赛→SYS-2/SYS-4，物联网竞赛→SYS-3，数学建模/大数据→SYS-1，挑战杯/互联网+→综合），平台统一组队训练；
   - **科研用人**：教师课题发布进平台，学生按子能力标签匹配进入课题组（论文/专利产出）；
   - **毕设需求**：毕设 S6 选题、S7 平台预研、真题真做，解决"准备不足、质量差"。
3. **同题异构跨专业协作**：智能系统创新设计等综合实践，AI/智科/计科分角色协同，一次实践三方获益。
4. **企业需求反向输入（向外）**：每年企业调研≥6 家，岗位能力清单反哺课程内容与平台项目库；生产实习 60% 项目来自企业。

## 七、考核指标体系（三层）

**学生层（能力达成）**
- 四子能力达成度评估表（每能力 3–5 个观测点，锚项目 + 实验记录评分）；
- SYS 作品集要求：毕业前至少完整交付 **2 个不同 SYS 类别**的作品（其一可为团队角色）；
- 竞赛/证书计入第二课堂学分。

**专业层（培养质量）**
- 毕业要求达成度年度评价（对接工程认证 2024 版）；
- 就业率与就业质量（对口率、起薪、企业满意度回访）；
- 申硕/考研上线率（申硕线看 B4 深度，就业线看 SYS 作品）。

**平台层（运行产出）**
- 年度竞赛获奖数（省级以上）、学生参与率；
- 年度科研成果（学生参与论文/专利/软著数）；
- 毕设优良率、真题比例（目标≥60%）；
- 平台作品库年入库数与复用率。

## 八、与工程认证 2024 版衔接要点

- 复杂工程问题七特征作为 SYS 项目立项审核标准（§2.4）；
- 四子能力映射毕业要求指标点，形成"课程—能力—毕业要求"支撑矩阵（后续按 2024 版智科表 4-1~4-4 模板展开）；
- 平台产出（竞赛/科研/毕设）作为"复杂工程问题解决能力"的直接达成证据链。
