# 从素材批量生成教案 — 工作流与踩坑笔记

本文件记录一次真实任务的完整链路（彭老师：9 个老格式 `.ppt` → 9 份 Word 教案，
套用《物联网概论》教案模板，授课对象智能科学 262/261 班），作为本技能的实操参考。

## 一、总体链路

```
源素材(.ppt/.pptx 若干)
      │
      ▼  extract_ppt_text.py        → 每章结构化文本（标题/知识点/要点）
模板 docx（含表格/合并单元格/宋体）
      │
      ▼  analyze_template.py        → 表0/表1/表2 的 (行,列) 坐标与字段
教案内容（Agent 依据提取文本撰写，含三维度目标、5 步教学过程）
      │
      ▼  generate_lesson_docx.py    → 复制模板 + 坐标填充，格式 100% 保留
 syllabus.docx（教学大纲）
      │
      ▼  提取课程编号/周次/考核方式/教材 → 并入 fills → 回填
      │
      ▼  verify_lessons.py          → 校验可打开、表格数、关键字段
```

## 二、每一步的关键判断

### 1) 选模板
- 一个课程目录里往往同时有「内容稿 docx」和「格式模板 docx」。
  **格式模板是含完整表格（课程信息表/教案主体表/教学内容表）的那一份**，
  内容稿只是某章文字，不是格式蓝本。
- 本任务中 `第一章绪论教案.docx` 才是格式模板；
  `第一章教案.docx` 只是第一章教学内容，被误当模板会丢表格。

### 2) 提取源文本（最易出坑）
- `.pptx` 直接用 python-pptx 读，干净。
- `.ppt`（OLE 老二进制）python-pptx 读不了。三条路：
  - **olefile + 多编码自动选优（采用）**：枚举所有流，逐流通吃
    utf-16-le / gbk / big5 / utf-8，用「常用汉字+领域词命中-乱码惩罚」打分选最优，
    再按领域词过滤噪声流。PPT 内常混简体(GBK)与繁体(Big5，如台湾高校素材)，
    纯猜一种编码必乱码。阈值 `score<25` 或不含汉字的流直接丢弃。
  - PowerPoint COM 转 pptx：本机虽有 Office，但隔离沙箱里 pywin32 的
    post-install 注册失败、且启动 GUI 可能被拦，放弃。
  - LibreOffice 转档：本机未安装，放弃。
- 提取后务必人工抽查前 1~2 章，确认不是乱码再继续写教案。

### 3) 模板坐标探查
- 用 `analyze_template.py` 打印所有表。记录：表0 R0C1=课程名称、R0C5=课程编号、
  R1C1=授课教师、R2C1=班级、R3C1=课程类别、R3C3=课程性质、R4C5=周次、
  R4C1=学分、R4C3=总学时理论、R5C3=实践学时、R6C1=考核方式、R7C1=教材、
  R8C1=参考资料；表1 R0C1=授课题目、R1C1=授课进度、R3C1=教学目标、
  R4C1=教学任务、R5C1=重点难点、R6C1=教学方法、R7C1=教学过程设计、
  R8C1=作业、R9C1=总结分析。**具体坐标依模板而定，必须实地探查，不可硬背。**

### 4) 写教案内容
- 每章含：授课题目、教学目标（知识/能力/素养三维度，可加思政）、教学任务、
  重点难点与突破、教学方法、5 步教学过程设计（时间/内容/师生活动/目标）、作业、总结分析。
- 文本用 `\n` 表示软换行，引擎会转成单元格内换行，不改变表格结构。
- 章号建议统一为中文数字（第一章…第九章）贴合模板。

### 5) 格式保持填充
- 引擎「先复制模板、再按坐标填空」，因此合并单元格、宋体 10.5pt、整体版式全部继承，
  **不会错位**。填写时沿用单元格首 run 的字体名/字号/加粗；并显式设置 w:eastAsia，
  确保中文在 Word 里是宋体而非默认西文字体。

### 6) 从教学大纲回填课程信息
- 大纲 docx 提取：课程代码、学分/总学时、课程类别/性质、考核方式（含比例）、
  教材（书名+作者+出版社+年份）、参考资料、教学进度周次。
- 周次映射：大纲常按「教学单元」给出（可能 9 章对应 8 个单元，末两章合并为 1 单元），
  需把周次摊回 9 个教案。本任务：第1~7章=第4~10周，第8、9章均落第11周。
- **编号差位必核对**：用户口述 `B1105T010772`，大纲印 `B1105T01077`，以用户给的为准
  但必须提示用户与教务数据核对。

## 三、常见待用户确认项（避免编造错误数据）
1. 课程编号（与大纲差位时）；
2. 教材具体版本与作者（模板常留占位）；
3. 学分/总学时/周次/考核方式（沿用模板值前需确认）；
4. 授课进度周次（是否末两章拆两次课 → 周次+1）；
5. 授课教师姓名/职称/教师类别（模板默认值）；
6. 封面校名/学期（模板默认值，如「西安航空学院 / 2026-2027-1」）。

## 四、验证清单
- [ ] 每个 docx 能被 python-docx 打开（无损坏）；
- [ ] 表格数 >= 2；
- [ ] 课程信息表关键字段已填（编号/教师/班级/教材/考核方式）；
- [ ] 表1 教学目标、5 步教学过程非空、无乱码；
- [ ] 字体为宋体、合并单元格无错位（抽查 1 份在 Word 打开看版式）。
