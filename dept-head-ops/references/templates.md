# 系主任运营工作流 · 模板库（T1–T8）

> 本文件供 `dept-head-ops` 技能直接套用。所有模板站在"系主任视角"，产出物用于审核拍板、督办与归档。

---

## T1 · 教师教学能力 / 意愿 / 时间摸底表

> 用途：Phase 1 曹敬馨发放，回收后建教师授课画像。三项（擅长课程/授课年限/往期评价）必填。
> 形式：可生成 Excel/在线表；此处给字段与示例行。

| 字段 | 说明 | 示例 |
|---|---|---|
| 姓名 | 专任教师 | 张三 |
| 擅长课程 | 能独立讲授、效果好的课程 | 机器学习、Python |
| 授课年限 | 该课程累计年限 | 机器学习 3 年 |
| 往期评价 | 近两次学生/督导评价等级 | 良好 |
| 授课意愿 | 下学期想上 / 不想上（注明） | 愿上机器学习 |
| 可排时间 | 不能排的时段（如周一上午有会） | 周一 1-2 节不可 |
| 备注 | 其他约束 | 愿带毕业设计 |

**发放话术（主任/曹转发）**：「各位老师，为做好下学期排课，请于 X 月 X 日前填妥本表，三项必填。排课将兼顾个人意愿与教学需求。」

## T6 · 任务派发 / 督办单

| 负责人 | |
| 协同 | |

## T8 · 中央督办台账与进度看板（state/backlog.csv）

> 用途：全系任务的**唯一真相源**。所有自动化（§十二）、派活脚本（§十四）、进度看板都读写此文件。主任/书记/委员看同一张表，杜绝"各记各的"。

**字段说明**

| 字段 | 含义 | 取值/示例 |
|---|---|---|
| id | 任务编号 | DH-20260926-01（自动生成） |
| task | 任务内容 | 完成下学期教师授课意愿摸底并回收 |
| owner | 负责人 | 曹敬馨 |
| co | 协同人 | 张晓丽（可空） |
| due | 截止日 | 2026-10-10（YYYY-MM-DD） |
| deliverable | 交付物 | T1 回收表 |
| supervisor | 督办人 | 彭寒（默认） |
| status | 状态 | 进行中 / 待拍板 / 已完成 / 逾期（系统自动转逾期） |
| source | 来源 | 系主任 / 系统定时 / 学院临时通知 |
| created | 创建日 | 2026-09-26 |
| note | 备注 | 逾期约谈依据、示例标记等 |

**进度看板样例（每周/月由 automation 生成推主任）**

```
📊 系部运营健康度（2026-09-26 更新）
─────────────────────────
✅ 进行中：3 项
   · DH-...-01 曹敬馨 排课摸底（截止 10-10）
   · DH-...-02 张晓丽 申硕材料（截止 10-15）
⏳ 待您拍板：1 项
   · DH-...-03 曹敬馨 排课初稿（已提交）
🔴 逾期：0 项
─────────────────────────
建议：今日拍板 DH-...-03，避免积压。
```

**使用纪律**
- 主任派活 → `push_task.py add` 自动入表 + 推责任人；
- 责任人回报 → 主任口头/文字告知本助手"DH-xxx 完成/待拍板"，本助手回填状态；
- 任何人不得以"没收到"为由拖延——企业微信推送 + 台账留痕即视为已送达。
