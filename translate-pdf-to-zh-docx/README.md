# translate-pdf-to-zh-docx

将英文学术 PDF 论文翻译为结构化的中文 Word（`.docx`）文档，质量接近 Google 翻译。

## 功能

- **保留真实结构**：章节标题层级、正文段落衔接（修复早期"一句一行"断开的问题）。
- **图片原位嵌入**：按双栏阅读顺序把原图截取到翻译稿对应位置。
- **表格真实翻译**：表格内容翻译为真正的 Word 表格，而非整表截图。
- **公式干净渲染**（v5 修复）：显示公式按页面原生宽度等比缩放、绝不放大；只裁剪数学字体区域，不再把整行文字吞进公式图。
- **版式净化**：剥离页码 / 页眉页脚噪声，设置中文字体、首行缩进、1.5 倍行距。

## 适用场景

- 用户要求将一篇或多篇 PDF 翻译为中文 Word。
- 用户抱怨之前翻译稿段落错乱、页眉页脚混入正文、表格乱码、公式变形 —— 本管线一次性修复以上四类问题。

## 环境要求

- Python 3.10+，需 `pymupdf`、`python-docx`（使用受管 venv）。
- 中国大陆需本地 HTTP 代理访问 Google 端点（默认 `http://127.0.0.1:7897`，可用环境变量 `TRANSLATE_PROXY` 覆盖）。
- 代理不可用时自动回退 MyMemory（质量较低，仅建议用于版式验证）。

## 用法

```bash
# 单篇 PDF 或目录（递归）；--force 重译已存在的 -翻译.docx，否则跳过
python scripts/translate_pipeline.py --force <pdf或目录> [更多参数...]

# 必做：校验输出
python scripts/verify_outputs.py <目录>
```

输出：每个源 PDF 旁边生成 `<原名>-翻译.docx`（真正的 Office Open XML，非 `.doc` 二进制）。
