# 六维审查逐条清单（含"红旗"信号）

> 每维逐条核对，命中"红旗"即记一条问题（严重程度按 SKILL §四 定义）。

## 维度1 · 差异化与错位竞争
- [ ] 三专业能否一句话区分？（AI 写程序 / 智科造系统 / 计科铸底座）
- [ ] 是否与学术型高校错位、定位应用型"能干活的人"
- [ ] 核心课程是否各自独有、无身份模糊
- 🚩 红旗：两个专业核心课高度同名同内容；定位描述可互换。

## 维度2 · 去冗余不断层
- [ ] 同一主题是否按"认知/应用/精通"分级而非重复开课
- [ ] 综合实践是否"同题异构"（一次实践三方分角色）
- [ ] 跨专业依赖是否有明确"接力点"
- 🚩 红旗：AI 与智科都开《深度学习》且大纲重叠；某专业孤立开课、上下游无人接。

## 维度3 · 能力培养主线（OBE）
- [ ] 每门课是否对应"能开发的系统"
- [ ] 有无"系统→子系统→功能→知识点→教学大纲"反向链路
- [ ] 是否有"课程→系统"反查表
- 🚩 红旗：出现无支撑系统的纯理论课（孤儿课）；课程清单里只有知识罗列、无系统出口。

## 维度4 · 应用型定位与课程瘦身
- [ ] 是否去掉偏难理论课（最优化等），换实用课
- [ ] 数学课是否只保留"直接可用"部分（矩阵/概率/向量空间）
- 🚩 红旗：仍开设与"能干活"弱相关的高阶理论课且占学分。

## 维度5 · 撤销专业"功能不撤销"
- [ ] 系统分析与设计/系统集成/体系结构 → 智科
- [ ] 算法分析与设计 → AI
- [ ] 五大部件 → 计科
- [ ] 传感/嵌入式/网络 → 三专业按需分配
- 🚩 红旗：原专业课程整门丢失、无去向；迁移后某能力无人承接。

## 维度6 · 工程教育认证 2024 版衔接
- [ ] 能否对接"课程—能力—毕业要求"支撑矩阵
- [ ] 毕业要求 12 条指标点是否均有课程支撑、无空白
- 🚩 红旗：核心课未映射到任何毕业要求指标点；指标点支撑课程为空。

## 跨专业对比附加项（三专业同审时）
- 同名/近名课程在三专业中的定位是否清晰（谁认知、谁应用、谁精通）
- 学期是否错位（如计科嵌入式须先于智科嵌入式开课）
- 共享课（如 7 门共享智能基础）排课与师资是否可协调
