# 培养方案审核检查清单（系主任用 · 合并八维版）

> 本文件是 `dept-head-review` skill 的逐条审查判据，整合了"专业负责人设计版"与"学位点汇聚版"两套口径。
> 每维给出"达标标准 + 常见失分项（🚩红旗信号）"，供逐项打勾并出具修订指令。
> 严重程度按 SKILL §四 定义：`阻塞`（违反铁律）/ `严重`（明显不达标）/ `建议`（润色类）。

## 维度 1 — 错位竞争（差异化定位）

**达标标准**
- 各专业有"一句话定位"且彼此不重叠：AI=造聪明软件 / 智科=构造智能系统（软硬协同）/ 计科=造计算机本身与底层硬件。
- 与 C9/985/211 形成错位（应用型、能力培养、区域/行业特色如航空），而非同质化理论堆叠。
- 课程体系中无三专业高度雷同的"重复开设"核心课。

**常见失分项 / 🚩红旗**
- 定位含混（如智科与计科都写成"做系统"，无软硬边界）。
- 理论课过多、过难（如最优化理论），偏离"能干活的人"目标。
- 为追"前沿"堆砌课程，缺乏能力出口。
- 🚩 两个专业核心课高度同名同内容；定位描述可互换。

## 维度 2 — 跨专业协同·同题异构 / 去冗余不断层

**达标标准**
- 存在"一次实践、三方获益"机制：AI 出算法、智科出系统、计科出底层载体。
- `reverse_cross.svg` 用箭头（建议 ≥20 条）证明能力闭环（边缘部署、视觉检测、雷达信号处理等）。
- 能说明多专业如何共享锚项目 / 竞赛 / 毕业设计。
- 同一主题按"认知/应用/精通"分级而非重复开课；跨专业依赖有明确"接力点"。

**常见失分项 / 🚩红旗**
- 三专业各自为政，无跨专业依赖图或依赖图箭头稀少、说不清闭环。
- 协同仅停留在"口号"，无具体课程/项目承接。
- 🚩 AI 与智科都开《深度学习》且大纲重叠；某专业孤立开课、上下游无人接。

## 维度 3 — OBE 一致性（能力培养主线）

**达标标准**
- 毕业要求 → 系统 → 子系统 → 能力 → 知识点 → 课程 全链路闭合。
- 每个能力点都有知识点与课程支撑，无"悬空能力"。
- 课程能回溯到明确的能力点与毕业要求指标点；具备"课程→系统"反查表。

**常见失分项 / 🚩红旗**
- 课程与能力点映射缺失或一对多混乱；知识点无对应课程（"学了但没课承载"）。
- 🚩 出现无支撑系统的纯理论课（孤儿课）；课程清单只有知识罗列、无系统出口。

## 维度 4 — 应用型定位与课程学分合理性（含瘦身）

**达标标准**
- 实用导向取舍，去除过难无用理论课（如最优化理论），换实用课。
- 数学课只保留"直接可用"部分（矩阵/概率/向量空间，是 RAG/大模型直接要用的实用数学）。
- 学分/学时结构合理，专业学位/非学位课占比满足认证（如 ≥50%）。
- 含前沿课与交叉课，体现行业特色（低空经济、航空智能制造等）。

**常见失分项 / 🚩红旗**
- 学分超载或结构失衡；缺前沿/交叉课，与区域产业脱节。
- 🚩 仍开设与"能干活"弱相关的高阶理论课且占学分。

## 维度 5 — 大图与编号规范（新增）

**达标标准**
- 五列结构完整：系统 / 子系统 / 功能能力 / 知识点 / 课程。
- **层级编号唯一**：系统=S1/Z1/J1，子系统=S1.1，能力=S1.1.1，知识点=S1.1.1.1；**无"S1 S1"类重复连写**、无断号（如 S1 与 S1.1 同级并列）。
- 锚项目、竞赛矩阵齐备；术语自解释（首次出现给中文全称/对照表）。
- 大图箭头方向清晰，表达分解与映射依赖。

**常见失分项 / 🚩红旗**
- 编号重复或断号；大图仅列课程，缺系统/能力层；箭头方向混乱。
- 文档引用 `SYS-`/`reverse_*.svg`/`B1–B4` 却不解释，外部读者看不懂。

## 维度 6 — 撤销专业"功能不撤销"迁移

**达标标准**
- 系统分析与设计 / 系统集成 / 体系结构 → 智科（系统搭建类）。
- 算法分析与设计 → AI。
- 计算机系统五大部件 → 计科。
- 传感 / 嵌入式 / 网络（物联网） → 三专业按需分配。
- 原专业课程整门迁移、无课程丢失、无能力断点。

**常见失分项 / 🚩红旗**
- 🚩 原专业课程整门丢失、无去向；迁移后某能力无人承接。

## 维度 7 — 工程教育认证 2024 版衔接

**达标标准**
- 能对接"课程—能力—毕业要求"支撑矩阵。
- 毕业要求 12 条指标点均应有课程支撑、无空白。

**常见失分项 / 🚩红旗**
- 🚩 核心课未映射到任何毕业要求指标点；指标点支撑课程为空。

## 维度 8 — 学位点汇聚（向上，新增）

**达标标准**
- 能把三专业产物转化为学位点培育建设方案（详见 `rollup-degree-plan.md`）：
  - 现状基础来自三专业（知识架构大图、课程清单、教材、锚项目、竞赛矩阵、本科毕业生基础）。
  - 差距分析逐项对比"申请基本条件"。
  - 经费测算、分年度里程碑清晰。
- 实验室设备若在建/待采购，归入"未来建设构想"，已采购单独标注。

**常见失分项 / 🚩红旗**
- 现状与申请条件脱节，差距表空洞。
- 把"在建/待采购"写成"已建/已落实"。
- 经费仅有总额，无分项与来源。

## 跨专业对比附加项（三专业同审时）

- 同名/近名课程在三专业中的定位是否清晰（谁认知、谁应用、谁精通）。
- 学期是否错位（如计科嵌入式须先于智科嵌入式开课）。
- 共享课（如 7 门共享智能基础）排课与师资是否可协调。
