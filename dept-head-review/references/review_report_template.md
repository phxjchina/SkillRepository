# 审核意见表 / 修订指令 模板

## 一、审核意见表（每次审查必填）

```
### 《<方案名>》审核意见（<单专业 / 三专业对比>）
总体结论：✅通过 / ⚠️修改后复审 / ⛔退回重做
六维速览：差异化[ ] 去冗余[ ] OBE[ ] 应用型[ ] 迁移[ ] 认证[ ]

| 序号 | 维度 | 位置(章节/课程) | 问题 | 严重程度 | 修改建议 |
|---|---|---|---|---|---|
| 1 | 去冗余 | 核心课程 | <问题> | 严重 | <建议> |
| 2 | OBE | 课程清单 | <问题> | 阻塞 | <建议> |
| 3 | 应用型 | 课程瘦身 | <问题> | 建议 | <建议> |

**严重程度**：阻塞（违反铁律，须改完才通过）｜严重（明显不达标，建议退回）｜建议（润色类，可后续改）
```

## 二、修订指令模板（交给 program-director-plan 执行）

```
### 修订指令（<日期>）
依据：《<方案名>》审核意见（结论：<⛔/⚠️>）

1. <专业> 专业：<具体操作，如"移除《最优化理论与方法》转智科核心；图神经网络/强化学习降为考研限选">
2. <专业> 专业：基于《<教材名>》目录，反推"<系统名>"并新增对应课程（系统→子系统→功能→知识点→大纲）
3. 跨专业：<如"共享智能科学基础只开一次，按认知/应用分级">
4. 验证：修订后回填"课程→系统"反查表，确保无孤儿课、无断层
```

## 三、审核结论用语建议

- ✅ 通过：六维均无阻塞/严重问题，仅少量建议项。
- ⚠️ 修改后复审：存在严重问题但方向正确，改完即可。
- ⛔ 退回重做：存在阻塞级问题（孤儿课、身份模糊、功能丢失、认证空白），须结构性调整。
