## F. 往届常见问题汇总（9 类，高频雷区）

1. **任务书**：缺签名/日期错/格式乱；工具与开题、论文不一致；论文内容与任务书不匹配或偏差大。
2. **开题报告**：现状多研究内容少；进度与任务书出入；个别参考文献近 3 年少；参考文献格式不规范；教师意见无针对性、相似度高；教师/教研室意见及日期签字有涂改或缺日期。
3. **开题答辩记录表**：内容偏少、潦草、涂改；地点不明确；小组人数不足或职称不合理。
4. **外文翻译**：图表未译、排版乱；缺教研室意见与日期、封面格式不统一；所引文献与毕业设计关联度低；未引用部分也打印入档或原文复印不规范；缺原文或工作量不够。
5. **工作记录**：缺指导方式/日期、内容打印、有涂改；"完成的任务、咨询的问题及指导内容"空泛，无具体指导与师生互动。
6. **论文初稿**：摘要不精练、不能体现主要内容；工作量不饱满；题目太大无对象、文不对题；内容不扣主题、各部分乱、缺深度与逻辑、缺优化策略；写作逻辑混乱、错误多；摘要宏观、用词不准、语句不通；关键词个别不准；目录格式不规范。
7. **教师责任心**：对学生要求不严，资料错误未指出；过程资料格式不规范未要求整改。
8. **学生态度**：对毕设重要性认识不足、态度不端正、不主动沟通，延缓进度影响质量。
9. **学院重视度**：自查与抽查严重不符；整体进展慢、初期问题整改不到位；校外毕设学生指导管理缺位。

## G. 陕西省本科毕业设计（论文）抽检评价要素

**毕业论文（5 指标）**
| 指标 | 评价要素 |
|---|---|
| 原创度与学术规范 | 合理学术不端检测标准内体现原创度、遵守学术规范；新见解/新方法有一定学术价值 |
| 选题规范性及选题意义 | 理论意义、实用性；选题新颖度、难易度、规范性；符合专业培养、体现综合训练 |
| 基础知识与专业能力 | 基础理论概念正确；理论基础扎实；专业知识系统性；综合运用知识技能分析解决问题；论据结论质量 |
| 论文结构规范性 | 语言准确专业、逻辑严密；结构安排合理；中英文摘要/目录/正文/参考文献结构完整 |
| 论文格式规范性 | 术语/图表/数据/公式/标点/空格规范、无错别字；引用标识规范；书写格式及图表规范 |

**本科毕业设计（4 指标）**
| 指标 | 评价要素 |
|---|---|
| 原创度 | 作品原创、不侵权、无抄袭剽窃；风格与形式语言有新意 |
| 选题规范性及选题现实意义 | 题材合法合规、抵制三俗；选题新颖度与规范性；符合专业培养、体现综合训练 |
| 基础知识与专业能力 | 体现教学大纲（培养方案）要求的技能；反映对专业基本理论/方法/技术手段熟练掌握 |
| 学术规范性 | 紧密联系自身创作实践、是对毕设理论或应用的原创性陈述；符合工程规范、兼顾社会/健康/安全/法律/文化/环境；行文流畅、用词准确、格式规范 |
