# 技术书稿成书发布流水线（tech-book-pipeline）

从"一堆工程档案 + 几篇长文"到"可发布的完整书稿 + 知乎系列"的标准流水线。
实战来源：《复杂系统建模与验证三十年》5 篇 18 章 + 附录、11.3 万字成书全过程（2026-09）。

## 总流程（六阶段）

```
素材盘点 → 成书蓝图 → 分批写作(片段插入法) → 清理与校验 → 整书生成+Word → 知乎拆分+配图+排期
```

### 阶段 0：素材盘点
- `wc -m` 统计现有正文各篇字符数，判断"综述体量"（3–5 万字）与"书的体量"（15–25 万字）差距。
- 数一遍档案库里"未被正文深描的工程/条目"——差距全在**展开率**而非素材。素材够不够的判据：未用条目数 × 每条可展开字数 ≥ 缺口。

### 阶段 1：成书蓝图（写成正式文档给用户审定）
必含四件：结构重排方案（如 4 篇 → 5 篇 18 章）、执行批次（B1–B8，每批 2–4 章约 3 万字）、防注水方法、发布红线。
防注水四法：① 档案展开（300 字条目 → 2000 字完整案例）；② 写前重读原始文档补第一手细节；③ 泛泛趋势改造成对照表；④ 每章末"理论透镜"收束防止两张皮。

### 阶段 2：分批写作（片段插入法）
- 每章一个独立 md 文件（`NN-书稿-第X章-标题.md`），章尾带页脚 `*（第 X 章完，约 N 字符。）*`。
- 增厚/补写用 **片段文件**（`_thick_NN.md`）+ 脚本插入。⚠️ **插入锚点必须选"参考文献节标题"之前，绝不能只锚页脚**——章尾结构是"正文 → 参考文献 → 页脚"，锚页脚会把新内容插到参考文献后面（实战踩坑，12 章中招）。
- 通用修复/插入脚本见 `scripts/fix_chapter_structure.py`（搬移文献后正文 + `###`→`##` 重编号 + 交叉引用盘点）。
- 每批写完立刻：插入 → 重算页脚字数 → 重生成整书 → 私人路径校验。

### 阶段 3：私人路径清理（公开发布红线）
- 目标：正文/参考文献零 `盘符:\` 路径、零"本机"字样、零内部文档名；引用全部替换为**可查证锚点**（DOI / arXiv 编号 / CORDIS 项目号 / 标准官网 / 出版社页）。
- 方法：**正则批量替换 + 参考文献整行重写**（`^\[X\].*$` 整行替换为干净版），不要用精确串匹配（`E:\` 反斜杠转义是重灾区）。
- Python 正则坑：替换串里的组引用写 `r'\g<1>'`，别写 `r'\1'`——`\1` 后跟数字（如 `\13`）会被当成组 13 报 `invalid group reference`。
- 内部文档（证据索引、逐工程明细）保留私人路径，但在文件头加"⚠️ 内部工作文档，请勿公开发布"横幅。
- 校验脚本见 `scripts/check_private_paths.py`（每次发布前必跑，零残留才算过）。
- **清理前先备份**原文件到 `_bak_publish/`。

### 阶段 4：整书生成 + Word
- 写一个幂等生成器 `_gen_book.py`：按章序拼接 md → 整书稿 md（含书名页/总目录/篇章分隔）。
- Word 转换用 python-docx：`#`→Heading、表格逐行写、引用块用斜体段落。产出书稿 docx。
- 章节源改了 → 重跑生成器 + 转换器即可，两者必须幂等可重跑。

### 阶段 5：知乎系列拆分
- 每章拆一篇，1700–3000 字（知乎舒适区）；**不是缩写是重写**：深描数据、对照表保留，长引用改口语化。
- 每篇结构：系列标记 → 一句话摘要（`> **一句话摘要**：…`，发布时直接贴知乎摘要栏）→ 封面图 → 正文 → "下一篇"导航。
- 封面图统一视觉体系（如深蓝工程蓝图 + 单色线稿 + 点睛色），**图中不放文字**（AI 生成中文必乱码）。
- ⚠️ **ImageGen 三坑**：① 并行调用会因秒级时间戳文件名互相覆盖（6 并行只存活 4 张）→ 必须严格串行；② output_dir 传嵌套子目录会被错误归并 → 直接传最终目录；③ 每张生成后立即重命名为 `NN.png`。
- 发布排期清单用脚本从各篇自动提取标题+摘要生成表格（建议每日一篇、开篇导流、完结篇置顶引流），参考 `scripts/gen_publish_list.py`。

## 红线清单（每批写完必查）
1. 零私人路径 / 零"本机" / 零内部文档名（grep 校验）
2. 节号无重复、标题级别统一（`##` 为主）
3. 参考文献全部可查证（DOI/arXiv/CORDIS/官网）
4. 关键史实（项目编号/预算/年份/伙伴数）经 WebSearch 核正后才写入
5. 产物归属确认：书稿类产物默认**私人空间**（资料库/本地），不进公开仓库；技能类沉淀（不含内容只含流程）才可公开

## 常用目录约定（可在工作区根 .workbuddy/memory 记录）
- `NN-书稿-第X章-*.md` 章节源 / `30-书稿-整书稿.md` 整书 / `_gen_book.py` 生成器
- `_thick_*.md` 增厚片段（留档追溯）/ `_bak_publish/` 清理前备份 / `知乎短文-成书系列/` 发布版
