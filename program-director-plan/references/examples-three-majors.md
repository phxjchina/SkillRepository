# 三专业真实分解实例（范本）

本文件给出已落地的三专业分解，作为 `program-director-plan` skill 的落地范本。编号前缀：S=人工智能，Z=智能科学与技术，J=计算机科学与技术。

## 人工智能 AI（造聪明软件）

- **定位**：算法与生成式应用，软为主。
- **8 个软件系统 S1–S8**（能力点 32、知识点 32）：
  - S1 企业智能知识库问答系统(RAG)
  - S2 多智能体自动化工作流系统
  - S3 智能视觉检测系统
  - S4 智能文本处理与对话系统
  - S5 本地大模型私有化部署与微调平台
  - S6 AI辅助软件开发平台
  - S7 智能数据分析与挖掘系统
  - S8 AI数字内容创作系统

## 智能科学与技术 智科（构造智能系统·软硬协同）

- **定位**：软硬协同，系统级集成 + 航空特色。
- **4 类目标系统 SYS-1~4**：智能信息处理 / 智能嵌入式 / 智能物联网 / 智能控制系统
- **4 种子能力 B1–B4**：信息系统开发 / 嵌入式开发 / 信息物理融合 / AI 算法模型（B = Base 能力基座）
- **10 个主干系统 Z1–Z10**（能力点 47、知识点 47）：
  - Z1 智能物联网系统(全反馈闭环)
  - Z2 自主导航与控制系统
  - Z3 低空安全防护与目标反制系统
  - Z4 边缘智能嵌入式系统
  - Z5 智能系统集成与综合实验平台
  - Z6 工业机器视觉系统
  - Z7 自主智能系统
  - Z8 智能机器人系统
  - Z9 具身智能与世界模型系统
  - Z10 物理AI与数字孪生系统

## 计算机科学与技术 计科（造计算机本身与底层硬件）

- **定位**：底层硬件、嵌入式、上位机、操作系统内核。
- **5 个硬件/系统 J1–J5**（能力点 20、知识点 20）：
  - J1 嵌入式测控系统
  - J2 上位机监控软件
  - J3 计算机硬件系统(五大部件)
  - J4 FPGA数字逻辑与接口系统
  - J5 操作系统内核与驱动

## 跨专业依赖 reverse_cross（同题异构闭环）

- **22 条箭头**证明三专业互相支撑：
  - 计科提供硬件 / 嵌入式 / 上位机底座
  - 智科提供系统级集成与航空特色
  - AI 提供算法模型与生成式应用
- 三者通过边缘部署、视觉检测、雷达信号处理等形成**能力闭环**。
- **含义**：学位点并非从零起步，而是建立在已跑通的三专业协同育人生态之上——这正是 "同题异构 PjBL" 的落地证据。

## 使用提示

- 新专业设计时，复用上述"定位一句话 + 目标系统清单 + 子能力链 + 锚项目"四步即可快速成形。
- 跨专业若存在重叠，优先用 reverse_cross 显式画出依赖箭头，避免"重复建设"质疑。
