# 三层课程结构与差异化规则汇总

## 一、三层课程结构

| 层 | 作用 | 多专业关系 | 示例（AI/智科/计科） |
|---|---|---|---|
| **基座课程** | 计算机 + 数学公共底座 | 三专业打通，**只开一次** | 数学3门 + 计算机公共8门（Python/离散/数据结构/组成/OS/网络/数据库/软工基础） |
| **核心课程** | 专业主干，决定专业身份 | 各校差异最大；每门只挂一个专业 | AI：算法分析/计算机视觉/NLP/智能数据挖掘/深度学习；智科：系统集成/航空嵌入式；计科：计算机组成/接口/OS内核 |
| **特色课程** | 差异化标签 | 各校自定 | AI：GenAI微专业群；智科：航空智能+/物理AI/世界模型/机器视觉；计科：FPGA/上位机 |

## 二、三专业差异化定位（错位竞争，一句话区分）

- **AI** = 构造**智能体程序**（算法/模型/Agent/大模型应用）。偏软、实用导向。
- **智科** = 构造**智能系统**（感知→传输→处理→计算→存储→控制 全反馈闭环）。软硬协同 + 航空智能+ + 具身智能。唯一覆盖"机器人/物理AI/世界模型"。
- **计科** = 构造**计算机系统五大部件**（输入/输出/计算/控制/存储）。硬件为基、嵌入式为矛、带上位机。

## 三、去冗余四规则（防重复、不断层）

1. **归属唯一**：每门专业核心/特色课只挂在一个专业名下；确需两专业共用的放入"共享层"，只开一次。
2. **深度分级**：同一主题（嵌入式、深度学习）按"认知级 / 应用级 / 精通级"三级区分——AI/智科用认知/应用级，计科用精通级，避免内容重叠。
3. **内容不越界**：AI 不教系统搭建（交给智科）；智科 不深教算法创新（交给 AI）；计科 不深教智能算法（交给 AI/智科）；各取所需、各授所长。
4. **实践同题异构**：综合实践（智能系统创新设计、物联网综合实验）采用"同场景、分角色"——AI 出算法、智科出系统集成、计科出硬件载体，一次实践三方获益，不重复开课。

## 四、撤销专业"功能不撤销"迁移规则（硬约束）

| 原专业课程 | 去向 | 理由 |
|---|---|---|
| 系统分析与设计 / 系统集成 / 体系结构设计（软件工程） | **智科** | 系统搭建类，归智科 |
| 算法分析与设计 | **AI** | 构造智能体程序 |
| 计算机系统五大部件（输入/输出/计算/控制/存储） | **计科** | 计算机底座 |
| 传感 / 嵌入式 / 网络（物联网工程） | **三专业按需分配** | 感知与通信是共性底座 |

> 原则：专业可取消，功能不能撤销。迁移后须无课程丢失、无能力断点。

## 五、课程瘦身规则（应用型导向）

- **判定标准**：该课是否直接服务"能开发的系统"？是否偏理论推导而非应用？是否符合应用型"能干活的人"定位？
- **典型处理**：
  - 偏难理论课（如最优化理论与方法）→ 移出应用型主线（可转给需要体系结构/集成优化的专业，或降为限选）。
  - 图神经网络 / 强化学习 等 → 降为"学术进阶限选"，仅考研线选修，不进实用主线。
  - 保留"实用数学"（如人工智能数学基础：只讲矩阵/概率/向量空间，是 RAG/大模型直接要用的），不是理论推导。

## 六、微专业融入规则

- 把微专业若干门课作为某专业"特色实践群"，按学期串成应用开发链（如 AI：RAG→多智能体→本地部署→AI短剧），不与原核心课重复。
- 若微专业某门"导论"可并入核心课（如"生成式AI导论"并入"生成式AI与AI大模型"），其余作特色实践群。

## 七、前沿方向转课程（非冗余切分示例）

- **世界模型** = 具身"大脑/想象力"（预测生成、规划前提）。
- **物理AI** = 训练"沙盘"（数字孪生/Omniverse/Isaac/Cosmos/Sim2Real）。
- 二者联动但不重复：世界模型课讲预测/生成，物理AI课讲仿真到现实的训练闭环，并设联合实验。
- **机器视觉 / 自主智能 / 机器人 / 具身智能** 同理按"系统→子系统→功能→知识点→课程"逐层反推（见 OBE 模板）。
