## 1. 体系演进时间线（按真实发生顺序，别跳步）

实验室 OS Agent 不是一次设计完的，而是**分阶段涌现**的。每加一层都先"试点→审阅→全量"，且任何新概念都先和彭老师对齐语义。

| 阶段 | 新增内容 | 关键产物 | 备注 |
|------|----------|----------|------|

| **B. 双端口** | + 导师管理驾驶舱（看板+主动推送） | 双端口架构 | 导师侧与学侧共享同一档案 |

## 2. 关键决策与纠偏（已踩过的坑，照做别重犯）

### 2.1 「世界模型」= 管理元框架（**最重要的一次纠正**）
- ❌ 误读：把"世界模型"当 AI 技术里的潜空间动力学小车原型（我做过 `world_model_lab/` 技术原型）。
- ✅ 彭老师原话：*"我所谓的世界模型，是说我把对实验室学生的管理作为一个世界模型来理解，就是整个的实验室 OS Agent 当成一个世界模型。"*
- **正解**：管理 / 元认知视角——整个体系（双端口·六专家·委员·感知·物理AI）**共同构成**这个世界模型，它是一种设计哲学而非一个模块。四要素：**状态 S / 动作 A / 动力学 T: S×A→S / 推演（先想象再执行）**。
- **同名异义必须澄清**：管理世界模型（Meta 层，对人/组织）= 体系本身；物理世界模型（P4 技术线，对物）= `world_model_lab/` 仅作同构示例。两者并列说明，不可混为一谈。

### 2.2 推广视频的字幕与声画
- 字幕**太大 → 去掉**，但保留原图片及图片上文字、保留调整后的语音。
- **声画同步**：卡片与口播必须 **1:1 对齐**，窗口严格按**真实配音时长**定（用 `ffprobe` 取分段时长，不要用计划时长）。

### 2.3 架构图风格
- 彭老师认可"国奖级"路线：渐变配色 + 卡片立体阴影 + 中文色标 chip + 平滑贝塞尔曲线动线 + 留白节奏。
- **视觉语言统一**：实线=静态包含/组成；蓝色虚线箭头=动态交互/数据控制流；颜色编码各域。
- 横图（1600×920）嵌竖屏视频时**严格保持原始比例**，用白框镶边+投影，绝不拉伸。

### 2.4 物理 AI 必须先"理解透彻"再加
- 不是贴标签。要讲清它与具身智能、世界模型、CPS 的层级区分，以及和本实验室"信息物理融合系统创客空间"身份的天然咬合（物理 AI = 长了 AI 大脑的新一代 CPS）。

## 4. 可复用工作流（脚本均在 `/workspace`）

### 4.1 配音短视频（edge-tts + ffmpeg）
- 流程：`edge-tts` 生成分段 mp3 → `concat` **解封装器**（非滤镜，避死锁）拼 `narration.mp3` → ffmpeg 叠加背景 + 卡片 + 音频。
- 脚本：`gen_ai_voice_video.py`（主合成）、`make_cards.py`（口播 1:1 卡片）、`align_voiceover.py`、`compose_video.py`。
- 音色开关：`VOICE=`（默认 `zh-CN-YunxiNeural` 男声；`Yunyang` 新闻腔；`Xiaoxiao` 女声）；`FORCE_TTS=1` 强制重生成。
- **ffmpeg 坑**（已验证）：
  - `concat` 滤镜在大文件会死锁 → 改用 `concat` 解封装器拼音频。
  - `trim=duration` 对 `stream_loop -1` 无限循环失效 → 改 `-stream_loop N`（有限）+ `-shortest`。
  - `-vf` 与 `-filter_complex` 不可混用 → scale 移入 filter_complex 链。
  - 编码：`-c:v libopenh264 -b:v 4M -pix_fmt yuv420p`；`-c:a aac -b:a 192k`；竖屏 1080×1920@24fps。

### 4.2 国奖级架构图（SVG → PNG → HTML 图集）
- 生成：`gen_arch_diagrams_pro.py` 输出 6 张 1600×920 SVG（`/workspace/arch-diagrams-pro/`）。
- 渲染：`chromium --headless=new --no-sandbox --screenshot` 转 PNG（中文稳妥；也可用 `cairosvg`）。
- 图集：`架构图集.html` 浏览器全屏，支持 ← → 翻页与点击圆点跳转。
- 6 张标准集：① CPS 全景 ② 管理架构分层 ③ 技术架构+物理AI 四拼图 ④ 信用·信念·情绪体系 ⑤ 世界模型动态闭环 ⑥ 物理AI 与 CPS 体现。

### 4.3 双区帧（图不拉伸 + 原视频文字保留）
- `make_diagram_frames.py`：把横图做成 1080×1920 **双区帧**——上半部架构图**严格等比**（1600×920→1000×575 白框镶边+投影），下半部半透明面板**逐字保留原配音版 6 张文字卡**（标题/要点/橙色落款）。
- `build_arch_video.py`：背景循环 + 6 段双区帧按口播卡点 `overlay enable='between(t,s,e)'` 叠加 + 旁白音轨；输出 `实验室OS_推广短视频_架构图版.mp4`。
- 校验：`ffprobe` 取分段时长定窗口；像素 diff 确认每张图卡点正确、图区比例=1.739 无拉伸。

### 4.4 学生包打包
- `tar -czf` 从 `/workspace` 以相对路径 `lab-os-agent-student-pack/...` 打包，含 `skills/`（v1.6.0）、`frameworks/`（15 份）、`world_model_lab/`、`promo-video/`（两份成片+口播稿+卡片+合成脚本+推广文）、`README.md`。
- 刻意排除：企微桥接、视频原始物料外链、个人笔记、lab-source 原始 docx。README 改写路径防断链。
- 回滚：旧版备份为 `-no-promo.tar.gz`（不含视频物料）等后缀。
