# 高校教师智能工作团 (uni-teacher-team)

覆盖一位高校计算机/人工智能系系主任、副教授的全工作景的 **Team 型 AI 协作专家团**：由统筹主理人统一调度，六位成员各司其职，按正式团队协作流程（TeamCreate → 调度 → 中转 → 汇编）完成专业产出。

## 类型
Team 型（多角色协作团队）

## 成员
| 成员 | 花名 | 职责 |
|------|------|------|
| uni-teacher-team-lead | 席统之（教务统筹总监） | 路由、调度、汇总 |
| ke-zhijiao | 柯知教（授课讲师） | 备课、课件、教材、大纲、考核 |
| fang-yucheng | 方育成（专业建设师） | OBE 反向设计、培养方案、微专业 |

## 复用的专用技能
`graduation-design-coach`、`graduation-supervisor`、`program-director-plan`、`dept-head-review`、`rssm-crown-verify`、`translate-pdf-to-zh-docx`、`ima-kb-rename-table`、`uni-teacher-teaching`、`uni-teacher-grant`、`uni-teacher-admin`、`uni-teacher-industry`。

## 隐私边界
本团所有产物均为角色能力抽象与模板，严禁读取/上传账号密码、个税、人事评分、合同金额、学生隐私等敏感数据；真实姓名与数字以占位符呈现，由用户本地填实。

## 头像
统一使用中性学术徽章（无真人肖像），保护隐私。

## 安装
将 `uni-teacher-team/` 目录放入专家目录后，运行注册使其可见：
```
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享
```
zip -r uni-teacher-team.zip uni-teacher-team/
```
